ما هي EC2 ولماذا تستخدمها What is EC2 and why

اسم EC2 اختصار لـ Elastic Compute Cloud، وهي خدمة تأجير الخوادم الافتراضية من AWS. تعدّ الأكثر استخداماً من بين خدمات AWS، وتمنحك تحكّماً كاملاً في نظام التشغيل ومكتبات التشغيل والتطبيقات.

EC2 stands for Elastic Compute Cloud — AWS's virtual server rental service. It's the most-used AWS service, giving you full control over the OS, runtime, and applications.

استئجار خوادم افتراضيةRent virtual machines

تختار نوع الخادم (CPU و RAM) ونظام التشغيل وتدفع بالساعة أو بالثانية.

Pick instance type (CPU/RAM), OS, pay per hour or per second.

تخزين على أقراص افتراضيةStorage on virtual disks

EBS للتخزين المستمرّ، Instance Store للأداء العالي، EFS للمشاركة بين الخوادم.

EBS for persistent, Instance Store for high perf, EFS for shared.

توزيع الحِملLoad balancing

Elastic Load Balancer يوزّع الطلبات على عدّة خوادم.

Elastic Load Balancer distributes traffic across instances.

توسعة تلقائيةAuto scaling

Auto Scaling Group يزيد/يقلّل عدد الخوادم حسب الحِمل.

Auto Scaling Group grows/shrinks instance count with demand.

تسمية أنواع الخوادم وقراءتها Reading instance type names

أسماء الخوادم في EC2 تتبع نمطاً موحّداً مثل m5.2xlarge. فهمك لهذا النمط ضروريّ لاختيار الخادم المناسب وللإجابة على أسئلة الامتحان.

EC2 instance names follow a standard pattern like m5.2xlarge. Understanding it is essential for choosing the right instance and for exam questions.

الجزءPartالمعنىMeaningمثالExample
الحرف الأولFirst letterفئة الاستخدام (الحساب، الذاكرة، التخزين، ...)Family (compute, memory, storage, ...)m = general, c = compute, r = memory
الرقمNumberالجيلGeneration5, 6, 7
الحجمSizeكمّية المواردResource sizenano, small, ..., 2xlarge, 24xlarge

فئات شائعةCommon families

m = عامّة الغرض (متوازن). c = حوسبة مكثّفة (CPU). r = ذاكرة كبيرة (RAM). i = تخزين محلّي سريع. t = بدأ باستخدامات خفيفة (burstable).

m = general purpose (balanced). c = compute-optimized. r = memory-optimized. i = storage-optimized. t = burstable.

وحدات الدفعBilling units

معظم الخوادم تُحسَب بالثانية (بحد أدنى 60 ثانية). ويندوز يُحسَب بالساعة. الدفع يبدأ من لحظة الإطلاق وينتهي عند الإيقاف.

Most Linux instances billed per second (min 60s). Windows billed per hour. Billing starts at launch, stops at shutdown.

نصيحة للامتحان:Exam tip: الـ t instances عندها مفهوم CPU Credits. لو استهلكت كل رصيدك، أداء الخادم يتراجع. T unlimited يسمح بتجاوز الرصيد مقابل تكلفة إضافية. t instances use CPU Credits. If you run out, performance throttles. T unlimited allows bursting beyond credits for extra cost.

خيارات الشراء (Pricing) Purchasing options

AWS تقدّم خمس طرق لشراء خوادم EC2، وكل طريقة لها حالة استخدام مختلفة. هذه أكثر المواضيع التي يسأل عنها الامتحان في سياق تحسين التكلفة.

AWS offers five ways to purchase EC2, each with a different use case. This is one of the most exam-tested topics around cost optimization.

On-DemandOn-Demand

ادفع بالساعة/الثانية بدون التزام. الأغلى لكنّه الأكثر مرونة. مناسب للأحمال غير المتوقّعة والتجارب القصيرة.

Pay per hour/second, no commitment. Most expensive but most flexible. Good for short unpredictable workloads.

Reserved InstancesReserved Instances

التزام سنة أو ثلاث سنوات بخصم حتى ٧٢٪. مناسب لأحمال ثابتة طويلة المدى (قواعد البيانات مثلاً).

1 or 3-year commitment, up to 72% discount. Good for steady long-running workloads (databases, etc.).

Savings PlansSavings Plans

التزام بـ $/ساعة بدلاً من خادم محدّد. أكثر مرونة من RI. يشمل EC2 و Lambda و Fargate.

Commit to $/hour rather than specific instance. More flexible than RI. Covers EC2, Lambda, Fargate.

Spot InstancesSpot Instances

خصم حتى ٩٠٪ مقابل إمكانية إنهاء الخادم بإشعار دقيقتين. مناسب لأعمال Batch و Big Data.

Up to 90% discount, can be terminated with 2-minute notice. Good for batch, Big Data jobs.

Dedicated HostsDedicated Hosts

خادم فيزيائيّ كامل مخصّص لك. للامتثال التنظيمي أو تراخيص BYOL.

Physical server dedicated to you. For compliance or BYOL licensing.

Dedicated InstancesDedicated Instances

خوادم على جهاز فيزيائي لا يشاركه غيرك، لكن AWS تديره. بديل أرخص من Dedicated Hosts.

Instances on hardware no other customer shares, but AWS manages. Cheaper than Dedicated Hosts.

مفهوم أساسي:Key concept: للاختيار في الامتحان: Spot للـ batch، Reserved للأحمال الثابتة، Savings Plans للمرونة، Dedicated للامتثال. On-Demand هو الافتراضي لكن الأغلى. Exam picks: Spot for batch, Reserved for steady workloads, Savings Plans for flexibility, Dedicated for compliance. On-Demand is default but priciest.

مجموعات الأمان (Security Groups) Security Groups

مجموعات الأمان هي جدار ناريّ افتراضيّ على مستوى الخادم. تحدّد أيّ المنافذ مفتوحة، ومن أيّ مصدر. تُطبَّق على مستوى ENI (Elastic Network Interface) لا على الخادم مباشرةً، ممّا يعني أنّ الخادم الواحد يمكن أن يرتبط بعدّة مجموعات.

Security Groups are virtual firewalls at the instance level. They define which ports are open and from which source. They apply to ENIs (Elastic Network Interfaces), not directly to instances, so one instance can attach multiple SGs.

الخاصّيةPropertyالسلوكBehavior
القواعدRulesAllow فقط. لا يوجد Deny. كل المنافذ مغلقة افتراضياً.Allow-only. No Deny rules. Everything closed by default.
الحالةStateStateful — الطلب الخارج يرجع تلقائياً (outbound reply allowed).Stateful — outbound replies auto-allowed.
المصدرSourceIP أو CIDR أو مجموعة أمان أخرى.IP, CIDR, or another Security Group.
النطاقScopeمرتبطة بـ VPC واحد. لا يمكن مشاركتها بين VPCs.Bound to one VPC. Not shareable across VPCs.
 
# Create a Security Group allowing SSH + HTTP
aws ec2 create-security-group \
  --group-name web-sg \
  --description 'Web server SG' \
  --vpc-id vpc-0a1b2c3d

# Allow SSH from your IP only
aws ec2 authorize-security-group-ingress \
  --group-id sg-0123abcd \
  --protocol tcp --port 22 --cidr 203.0.113.5/32

# Allow HTTP from anywhere
aws ec2 authorize-security-group-ingress \
  --group-id sg-0123abcd \
  --protocol tcp --port 80 --cidr 0.0.0.0/0
فخّ شائع:Common pitfall: Connection refused يعني أنّ التطبيق لا يستمع على المنفذ (مشكلة في الخادم). Connection timeout يعني أنّ الطلب لم يصل أصلاً (مشكلة في Security Group أو Network ACL). هذا الفرق يُسأل كثيراً في الامتحان. Connection refused = application not listening on port (server problem). Connection timeout = request never arrived (Security Group or NACL problem). This distinction is asked frequently.

أزواج المفاتيح (Key Pairs) و User Data Key Pairs & User Data

للاتّصال بخوادم Linux عبر SSH تحتاج إلى زوج مفاتيح (Key Pair): مفتاح عامّ تحتفظ به AWS ومفتاح خاصّ تنزّله مرّة واحدة. ولا يمكن استرجاع المفتاح الخاصّ إذا ضاع — ستحتاج لإنشاء زوج جديد.

To SSH into Linux instances you need a Key Pair: public key kept by AWS, private key downloaded once. If the private key is lost, you cannot recover it — you must generate a new pair.

# Connect via SSH (after setting permissions on the .pem file)
chmod 400 ~/.ssh/acme-prod.pem
ssh -i ~/.ssh/acme-prod.pem ec2-user@ec2-54-123-45-67.compute-1.amazonaws.com

# 'ec2-user' is the default user for Amazon Linux
# 'ubuntu' for Ubuntu, 'admin' for Debian, 'centos' for CentOS

User Data هو سكربت bash يعمل مرّة واحدة عند أوّل إطلاق للخادم. يُستخدم لتثبيت البرامج وتحديث النظام وتشغيل الخدمات تلقائياً. يعمل بصلاحيات root. حجمه لا يتجاوز ١٦ كيلوبايت.

User Data is a bash script that runs once on first instance boot. Used to install software, patch the system, start services automatically. Runs as root. Max 16KB.

#!/bin/bash
# Example user data for a web server
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
echo '<h1>Hello from Acme Corp</h1>' > /var/www/html/index.html
نصيحة للامتحان:Exam tip: User Data مشفّر بـ base64 عند الإرسال، لكنّه يُحفَظ على الخادم بصيغة غير مشفّرة في /var/lib/cloud/instance/user-data.txt. لا تضع أسراراً في User Data؛ استخدم Secrets Manager أو SSM Parameter Store. User Data is base64-encoded in transit but stored unencrypted at /var/lib/cloud/instance/user-data.txt. Never put secrets in User Data — use Secrets Manager or SSM Parameter Store.

حالات الخادم وإدارته من SDK Instance states & SDK management

للخادم في EC2 ستّ حالات رئيسية. فهمها مهمّ لأنّ الامتحان يسأل عن الفرق في السلوك والتسعير بين الحالات.

EC2 instances have 6 main states. Understanding them matters because the exam asks about behavior and billing differences.

الحالةStateالسلوكBehaviorالفوترةBilling
pendingيبدأ الإطلاقBootingلا تُحتسَبNot billed
runningيعمل طبيعياًOperating normallyتُحتسَب كاملFull billing
stoppingيتم إيقافهShutting downتُحتسَبBilled
stoppedموقوف — البيانات في EBS محفوظة، IP العام يتغيّر عند إعادة التشغيلStopped — EBS data persists, public IP changes on restartEBS فقطEBS only
shutting-downيتم حذفهBeing terminatedلا تُحتسَبNot billed
terminatedمحذوف نهائياً. EBS يُحذَف افتراضياًPermanently deleted. EBS deleted by defaultلا تُحتسَبNot billed
 
// Java SDK v2 — launch a new EC2 instance
import software.amazon.awssdk.services.ec2.Ec2Client;
import software.amazon.awssdk.services.ec2.model.*;

Ec2Client ec2 = Ec2Client.create();

RunInstancesResponse response = ec2.runInstances(RunInstancesRequest.builder()
    .imageId("ami-0abc1234")              // Amazon Linux AMI
    .instanceType(InstanceType.T3_MICRO)
    .minCount(1).maxCount(1)
    .keyName("acme-prod")
    .securityGroupIds("sg-0123abcd")
    .userData(java.util.Base64.getEncoder()
        .encodeToString("#!/bin/bash\nyum install -y httpd".getBytes()))
    .build());

String instanceId = response.instances().get(0).instanceId();
System.out.println("Launched: " + instanceId);
للمطوّر السينيور:For the senior dev: الـ Ec2Client في Java SDK v2 يدير retries و signing تلقائياً. عند تشغيله داخل خادم EC2 آخر، يأخذ الصلاحيات تلقائياً من الـ IAM Role المرتبط بالخادم (Instance Profile). لا تضع مفاتيح في الكود أبداً. Java SDK v2 Ec2Client handles retries and signing automatically. When running inside another EC2 instance, it picks up credentials from the attached IAM Role (Instance Profile). Never hardcode keys.

الهدف: إطلاق خادم EC2 صغير، والاتّصال به عبر SSH، ثم إيقافه وحذفه.

Goal: Launch a small EC2 instance, SSH in, then stop and terminate it.

    Save the .pem somewhere safe — you cannot re-download it.

  3. ٣

    اسمح بـ SSH من IP الخاصّ بك Allow SSH from your IP only

    في Security Group: أضف قاعدة port 22 من My IP (أضيق نطاق ممكن).

    In Security Group: add rule port 22 from My IP (narrowest possible range).

  4. ٤

    اتّصل واختبر Connect and test 

    chmod 400 ~/Downloads/my-key.pem

# Inside the instance:
uname -a

  5. ٥

    أوقف الخادم ثم احذفه Stop then terminate

    لا تترك خادماً شغّالاً بدون حاجة. حتى t3.micro بعد تجاوز Free Tier يكلّف حوالي ٨ دولارات شهرياً.

    Don't leave instances running unused. Even t3.micro after Free Tier is ~$8/month.

تنبيه: Warning: احذف الـ Security Group والـ Key Pair إن لم تعد بحاجة إليهما. الـ Volumes المرتبطة بـ terminated instance تُحذَف افتراضياً إلّا إذا غيّرت Delete on Termination. Delete the Security Group and Key Pair if unused. EBS volumes attached to a terminated instance are deleted by default unless Delete on Termination was unchecked.

للحفظ السريع: Mnemonic:

للتمييز بين timeout و refused: Timeout = ما وصل أصلاً (Security Group). Refused = وصل لكن ما في خدمة (التطبيق متوقّف). فكّر فيها كـ "الباب مقفول" vs "الباب مفتوح لكن ما في أحد".

To distinguish timeout vs refused: Timeout = never arrived (Security Group). Refused = arrived but no listener (app down). Think "locked door" vs "open door, no one home".
