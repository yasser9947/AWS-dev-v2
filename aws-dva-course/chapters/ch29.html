ما هو CloudFront؟ What is CloudFront?

Amazon CloudFront شبكة توصيل محتوى عالميّة (CDN) بمئات من نقاط الحضور (Edge Locations). تخزّن المحتوى مؤقّتاً قرب المستخدمين لتسريع القراءة، وتحمي من DDoS (بالتكامل مع Shield و WAF). تعتمد عليها خدمات AWS نفسها في نقل البيانات.

Amazon CloudFront is AWS's global CDN with hundreds of Edge Locations. It caches content close to users to accelerate reads, and absorbs DDoS (integrates with Shield and WAF). AWS services themselves rely on it for data transfer.

CloudFrontCloudFront

Edge عالميّ. يخزّن مؤقّتاً لـ TTL (يوم مثلاً). مثاليّ لمحتوى ساكن يجب أن يكون متاحاً في كلّ مكان.

Global edge network. Caches per TTL (maybe a day). Ideal for static content that must be available everywhere.

إعداد لكلّ منطقة مستهدفة. تحديث قريب من الفوريّ. مناسب لمحتوى ديناميكيّ في عدد محدود من المناطق.

Configured per destination region. Updates near real-time. Suits dynamic content in a few regions.

Cache Keys و Policies و Behaviors Cache Keys, Policies & Behaviors

المفتاح الذي يحدّد "هل هذا الطلب موجود في الكاش؟" هو Cache Key. افتراضياً يتألّف من hostname + URL path. يمكن عبر Cache Policy إضافة HTTP headers أو cookies أو query strings إلى المفتاح (للتنويع حسب مستخدم/لغة/جهاز).

The Cache Key determines "is this request cached?". By default it's hostname + URL path. Using a Cache Policy you can include HTTP headers, cookies, or query strings in the key (to vary per user/language/device).

مفهوم أساسي:Key concept: مفهوم مهمّ: Cache Policy vs Origin Request Policy. الأولى تحدّد ما يدخل في Cache Key (يتحكّم بالتنويع). الثانية تحدّد ما يُمرَّر إلى Origin دون دخوله في المفتاح (مفيد لمعلومات تُوثِّق لكن لا تفرّق الكاش). Key distinction: Cache Policy vs Origin Request Policy. First = what enters the Cache Key (controls cache variance). Second = what is forwarded to origin without entering the key (useful for auth info that shouldn't fragment cache).

Cache Behaviors توجّه كلّ path pattern إلى origin وسلوك مختلف. مثلاً /api/* → ALB (بدون كاش)، /images/* → S3 (بكاش طويل)، /* → الافتراضيّ. الـ /* دائماً آخر ما يُقيَّم.

Cache Behaviors route path patterns to different origins and rules. E.g., /api/* → ALB (no cache), /images/* → S3 (long cache), /* → default. The /* default is always last to evaluate.

تأمين المحتوى الخاصّ: OAC و Signed URLs/Cookies Securing private content: OAC, Signed URLs/Cookies

لربط S3 بـ CloudFront بشكل آمن، استخدم OAC (Origin Access Control) — البديل الحديث لـ OAI الذي صار deprecated. OAC يحقن signing توقيع SigV4 ويتكامل مع Bucket Policy لتخصيص S3 فقط لـ CloudFront. هو الإجابة الصحيحة في الامتحان اليوم.

To securely link S3 to CloudFront, use OAC (Origin Access Control) — the modern replacement for the now-deprecated OAI. OAC injects SigV4 signing and integrates with the Bucket Policy so S3 only accepts CloudFront. This is the current-exam right answer.

Signed URLSigned URL

رابط واحد لكلّ ملف. مناسب للتنزيل الفرديّ مثل مقاطع فيديو مدفوعة.

One URL per file. Good for single-item downloads like premium videos.

Signed CookiesSigned Cookies

كوكي واحد يفتح عدّة ملفّات (مجلّد أو نمط). مناسب لبوّابة موقع تتطلّب اشتراكاً.

One cookie unlocks many files (folder / pattern). Ideal for a subscription-gated site.

Lambda@Edge و ميّزات أخرى Lambda@Edge & other features

Lambda@Edge يشغّل دوالّ Node.js/Python عند ٤ نقاط في دورة الطلب: Viewer Request (قبل فحص الكاش)، Origin Request (قبل الذهاب للـ origin)، Origin Response (بعد عودة الـ origin)، Viewer Response (قبل الإرجاع للمستخدم). يُستخدم لتعديل headers، A/B testing، auth، تحويل URL.

Lambda@Edge runs Node.js/Python functions at 4 hooks in the request cycle: Viewer Request (before cache check), Origin Request (before origin), Origin Response (after origin), Viewer Response (before sending to viewer). Used for header manipulation, A/B testing, auth, URL rewriting.

Geographic RestrictionGeographic Restriction

Allowlist/Blocklist للدول للامتثال لحقوق النشر. Geo-IP من مزوّد خارجيّ.

Country allowlist/blocklist for copyright compliance. 3rd-party Geo-IP.

All (كلّ المناطق، أغلى)، ٢٠٠ (بدون الأغلى)، ١٠٠ (الأرخص فقط: أمريكا/أوروبا).

All (everywhere, priciest), 200 (exclude costliest), 100 (cheapest only: US/EU).

Origin GroupsOrigin Groups

أصل أساسي + احتياطي. فشل الأوّل → الثاني. high availability.

Primary + secondary origin. Fail first → second. High availability.

Field-Level EncryptionField-Level Encryption

تشفير حقول محدّدة في POST (حتى ١٠) بمفتاح عامّ على الـ edge. طبقة أمان إضافيّة فوق HTTPS.

Encrypt specific POST fields (up to 10) with a public key at the edge. Extra layer above HTTPS.

CloudFront Real-time Logs تبثّ الطلبات إلى Kinesis Data Streams للتحليل الفوريّ بـ Lambda أو Firehose. مختلفة عن Standard Logs في S3 التي تصل بتأخير.

CloudFront Real-time Logs push requests to Kinesis Data Streams for instant analysis via Lambda or Firehose. Different from Standard Logs in S3 which are delayed.

ربط CloudFront بـ Java/Spring Boot Wiring CloudFront to a Spring Boot API

نمط معياريّ: CloudFront أمام ALB عام يوجّه إلى Auto Scaling Group من خوادم Spring Boot. /static/* يذهب إلى S3، و /api/* إلى ALB. هذا يسرّع الموقع ويحمي API من DDoS.

Canonical pattern: CloudFront in front of a public ALB routing to an Auto Scaling Group of Spring Boot instances. /static/* → S3, /api/* → ALB. Speeds up the site and protects API from DDoS.

// Spring Boot: trust CloudFront's X-Forwarded headers
@Configuration
public class ForwardedHeaderConfig {

    @Bean
    public FilterRegistrationBean<ForwardedHeaderFilter> forwardedHeaderFilter() {
        FilterRegistrationBean<ForwardedHeaderFilter> bean =
            new FilterRegistrationBean<>(new ForwardedHeaderFilter());
        bean.setOrder(Ordered.HIGHEST_PRECEDENCE);
        return bean;
    }
}

// application.yml
// server.forward-headers-strategy: framework
نصيحة للامتحان:Exam tip: عند استخدام Public ALB أصلاً: اقيّد Security Group بحيث يقبل فقط IPs الخاصّة بـ CloudFront Edge (AWS تنشر هذه القائمة في managed prefix list com.amazonaws.global.cloudfront.origin-facing) لمنع التجاوز المباشر للـ CloudFront. When using a public ALB as origin: restrict the SG to CloudFront's edge IPs (AWS provides a managed prefix list com.amazonaws.global.cloudfront.origin-facing) to prevent bypassing CloudFront directly.
