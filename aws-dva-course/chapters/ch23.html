ما هو CDK ولماذا هو مثاليّ لمطوّر Java What is CDK and why it fits Java developers

AWS CDK يسمح لك بتعريف بنية AWS التحتية بـ TypeScript، Python، Java، .NET، Go. تحصل على IntelliSense و Type Safety و Loops و Methods، ثم CDK يُولّد قالب CloudFormation كامل.

AWS CDK lets you define AWS infrastructure in TypeScript, Python, Java, .NET, Go. You get IntelliSense, type safety, loops, and methods, then CDK generates a full CloudFormation template.

CloudFormation / SAMCloudFormation / SAM

YAML/JSON declarative. بسيط لكن: لا loops، لا if عميق، تكرار كثير عند التوسّع.

Declarative YAML/JSON. Simple but: no loops, shallow if, lots of repetition at scale.

CDKCDK

لغة برمجة حقيقيّة. يمكنك استخدام loops و classes و libraries. يُنتج CloudFormation. ممتاز للـ Java developer.

Real programming language. Use loops, classes, libraries. Emits CloudFormation. Excellent for Java devs.

// Java example: VPC + ECS Fargate Service
package com.acme;

import software.amazon.awscdk.*;
import software.amazon.awscdk.services.ec2.Vpc;
import software.amazon.awscdk.services.ecs.Cluster;
import software.amazon.awscdk.services.ecs.patterns.*;
import software.amazon.awscdk.services.ecs.ContainerImage;
import software.constructs.Construct;

public class AcmeServiceStack extends Stack {
    public AcmeServiceStack(final Construct scope, final String id, final StackProps props) {
        super(scope, id, props);

        Vpc vpc = Vpc.Builder.create(this, "AcmeVpc")
            .maxAzs(2).build();

        Cluster cluster = Cluster.Builder.create(this, "Cluster")
            .vpc(vpc).build();

        // L3 construct — generates ~20 CloudFormation resources
        ApplicationLoadBalancedFargateService.Builder.create(this, "Service")
            .cluster(cluster)
            .cpu(512).memoryLimitMiB(1024)
            .desiredCount(2)
            .taskImageOptions(
                ApplicationLoadBalancedTaskImageOptions.builder()
                    .image(ContainerImage.fromRegistry("amazon/amazon-ecs-sample"))
                    .containerPort(80)
                    .build())
            .publicLoadBalancer(true)
            .build();
    }
}
للمطوّر السينيور:For the senior dev: للـ Java developer: CDK يُضاف عبر pom.xml كـ dependencies عادية. تستخدم Maven للبناء، و cdk deploy للنشر. الـ IDE (IntelliJ/VS Code) يقدّم auto-completion كامل لجميع موارد AWS. For Java devs: CDK is added via pom.xml like any dependency. Use Maven to build, cdk deploy to deploy. Your IDE (IntelliJ/VS Code) gives full autocomplete for every AWS resource.

Constructs L1، L2، L3 Constructs L1, L2, L3

Construct هو اللبنة الأساسيّة في CDK. يُمثّل مورداً واحداً أو مجموعة موارد. تأتي بثلاثة مستويات: L1 (عام، خريطة مباشرة لـ CloudFormation)، L2 (intent-based، أكثر ذكاءً)، L3 (Patterns جاهزة).

A Construct is CDK's building block. Represents one resource or a group. Three levels: L1 (raw, direct CloudFormation mapping), L2 (intent-based, smarter), L3 (ready patterns).

// TypeScript example to contrast L1 vs L2 vs L3
import * as s3 from 'aws-cdk-lib/aws-s3';
import * as ecs_patterns from 'aws-cdk-lib/aws-ecs-patterns';

// L1 — manual, every property required
const l1Bucket = new s3.CfnBucket(this, 'L1Bucket', {
  bucketName: 'acme-l1',
  versioningConfiguration: { status: 'Enabled' },
  bucketEncryption: {
    serverSideEncryptionConfiguration: [
      { serverSideEncryptionByDefault: { sseAlgorithm: 'AES256' } }
    ]
  }
});

// L2 — smart defaults, helper methods
const l2Bucket = new s3.Bucket(this, 'L2Bucket', {
  versioned: true,
  encryption: s3.BucketEncryption.S3_MANAGED,
  blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL
});
l2Bucket.grantRead(lambdaFn);        // auto-generates IAM policy

// L3 — whole pattern
new ecs_patterns.ApplicationLoadBalancedFargateService(this, 'Service', {
  cluster, cpu: 512, memoryLimitMiB: 1024,
  taskImageOptions: { image: ecs.ContainerImage.fromRegistry('nginx') }
});
// Generates: VPC, ECS Cluster, Task Def, Service, ALB, Target Group, SG, IAM — one call
مفهوم أساسي:Key concept: Construct Hub (constructs.dev) يحتوي مكتبة Constructs من AWS ومن المجتمع — يمكن تثبيت أيّ منها كـ package (npm، Maven، pip). Construct Hub (constructs.dev) hosts Constructs from AWS and the community — install any as a package (npm, Maven, pip).

الأوامر الأساسيّة: synth، deploy، diff Core commands: synth, deploy, diff

الدورة النموذجيّة: كتابة الكود، cdk synth لرؤية CloudFormation الناتج، cdk diff لمعاينة التغييرات، cdk deploy للتنفيذ. كل هذا فوق CloudFormation تحت الغطاء.

Typical flow: write code, cdk synth to see generated CloudFormation, cdk diff to preview changes, cdk deploy to execute. All on top of CloudFormation under the hood.

Testing، Aspects، و CDK vs SAM Testing, Aspects & CDK vs SAM

لأنّ CDK كود، يمكن اختباره. Fine-grained Assertions يتحقّقون من وجود موارد معيّنة بخصائص معيّنة. Snapshot Tests يقارنون الإخراج مع قاعدة مُخزَّنة. Aspects تُطبِّق قاعدة على كل الموارد (مثل tagging إلزاميّ).

Since CDK is code, it can be tested. Fine-grained assertions verify specific resources with specific properties. Snapshot tests compare output with a stored baseline. Aspects apply a rule across all resources (e.g. mandatory tagging).

// Jest test for a CDK stack
import { Template } from 'aws-cdk-lib/assertions';
import { Stack } from 'aws-cdk-lib';
import { MyStack } from '../lib/my-stack';

test('Lambda is created with correct runtime', () => {
  const app = new App();
  const stack = new MyStack(app, 'Test');
  const template = Template.fromStack(stack);

  // Fine-grained assertion
  template.hasResourceProperties('AWS::Lambda::Function', {
    Handler: 'index.handler',
    Runtime: 'nodejs20.x',
  });
  template.resourceCountIs('AWS::SNS::Topic', 1);

  // Snapshot test
  expect(template.toJSON()).toMatchSnapshot();
});

الهدف: إنشاء ونشر Stack CDK بـ Java يحتوي على S3 Bucket و Lambda.

Goal: Create and deploy a Java CDK stack with an S3 bucket and a Lambda.

  1. ١

    ثبّت CDK CLI Install CDK CLI 

    npm install -g aws-cdk
cdk --version
  2. ٢

    أنشئ مشروع Java جديد Scaffold a new Java project 

    mkdir acme-cdk && cd acme-cdk
cdk init app --language=java
# Creates pom.xml, src/main/java/com/myorg/AcmeCdkStack.java
  3. ٣

    أضف S3 Bucket و Lambda Add S3 Bucket and Lambda 

    import software.amazon.awscdk.services.s3.Bucket;
import software.amazon.awscdk.services.lambda.Function;
import software.amazon.awscdk.services.lambda.Runtime;
import software.amazon.awscdk.services.lambda.Code;

Bucket bucket = Bucket.Builder.create(this, "AcmeBucket")
    .versioned(true).build();

Function fn = Function.Builder.create(this, "AcmeFn")
    .runtime(Runtime.JAVA_17)
    .handler("com.acme.Handler::handleRequest")
    .code(Code.fromAsset("target/my-jar.jar"))
    .memorySize(512).build();

bucket.grantRead(fn);  // auto-generates IAM
  4. ٤

    Bootstrap وانشر Bootstrap & deploy 

    cdk bootstrap
cdk synth           # preview CloudFormation
cdk diff            # diff against deployed
cdk deploy          # creates the stack
  5. ٥

    تنظيف Cleanup 

    cdk destroy
تنبيه: Warning: Bootstrap يُنشِئ S3 Bucket يحتاج حذفه يدوياً لو أردت إزالة كل الأثر. يحتاج pom.xml و Maven مثبّت لـ Java. Bootstrap creates an S3 bucket you must delete manually to wipe every trace. Requires a pom.xml and Maven installed for Java.
