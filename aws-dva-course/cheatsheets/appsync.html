AWS AppSync

خدمة GraphQL مُدارة مع اشتراكات فورية ومصادر بيانات متعدّدة (DynamoDB، Lambda، RDS، OpenSearch، HTTP). Managed GraphQL service with real-time subscriptions and multiple data sources (DynamoDB, Lambda, RDS, OpenSearch, HTTP).

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
GraphQL Schema مخطّط موحّد يصف الأنواع والاستعلامات (Query) والتعديلات (Mutation) والاشتراكات (Subscription). Single schema describing types, queries, mutations, and subscriptions.
Resolvers ربط كل حقل بمصدر بيانات عبر VTL أو JavaScript Resolvers. Map each field to a data source via VTL or JavaScript resolvers.
Data Sources DynamoDB، Lambda، RDS (Data API)، OpenSearch، HTTP، EventBridge، None. DynamoDB, Lambda, RDS (Data API), OpenSearch, HTTP, EventBridge, None.
Subscriptions WebSocket تلقائي لتلقّي التحديثات الفورية عند تشغيل Mutation. Auto-managed WebSocket to receive real-time updates when mutations fire.
Authorization Modes API Key، IAM، Cognito User Pools، OIDC، Lambda؛ يمكن تفعيل أكثر من وضع معًا. API Key, IAM, Cognito User Pools, OIDC, Lambda; multiple modes supported.
Caching كاش على مستوى الحلّ (Resolver) أو كامل الـ API مع TTL قابل للتكوين. Per-resolver or full-API caching with configurable TTL.
Pipeline Resolvers تنفيذ سلسلة وظائف (functions) قبل/بعد مصدر البيانات. Chain multiple functions before/after a data source.
Delta Sync مزامنة تفاضلية لتطبيقات الجوّال مع DynamoDB. Differential sync for mobile/offline clients with DynamoDB.

أوامر CLI الأساسية Essential CLI Commands

إنشاء GraphQL API. Create a GraphQL API. 

aws appsync create-graphql-api --name OrdersGraphQL --authentication-type API_KEY

إنشاء Data Source من DynamoDB. Create a DynamoDB data source. 

aws appsync create-data-source --api-id abcd1234 --name OrdersTable --type AMAZON_DYNAMODB --dynamodb-config tableName=Orders,awsRegion=us-east-1 --service-role-arn arn:aws:iam::111:role/AppSyncDDB

رفع مخطّط GraphQL. Upload a GraphQL schema. 

aws appsync start-schema-creation --api-id abcd1234 --definition fileb://schema.graphql

إنشاء Resolver. Create a resolver. 

aws appsync create-resolver --api-id abcd1234 --type-name Query --field-name getOrder --data-source-name OrdersTable --request-mapping-template file://req.vtl --response-mapping-template file://res.vtl

تمكين Caching لـ API كاملة. Enable full-API caching. 

aws appsync create-api-cache --api-id abcd1234 --ttl 300 --api-caching-behavior FULL_REQUEST_CACHING --type SMALL

نصائح للامتحان Exam Tips

AppSync يوفّر WebSocket subscriptions بشكل أصلي بدون إدارة اتصالات يدويًا. AppSync provides native WebSocket subscriptions without manual connection management.
يمكن تفعيل عدّة Authorization Modes في نفس الـ API لمواطن استخدام مختلفة. Multiple authorization modes can be enabled on the same API for different use cases.
Resolvers VTL تستخدم Velocity Template؛ بدلاً منها يمكن استخدام JavaScript Resolvers الجديدة. VTL resolvers use Velocity; modern alternative is JavaScript resolvers.
للتكامل مع RDS استخدم Data API (بدون إدارة اتصالات). For RDS integration use the Data API (no connection management).
Caching في AppSync يقلّل عمليات Dynamo/Lambda ويحسّن زمن الاستجابة. Caching in AppSync reduces Dynamo/Lambda calls and improves latency.
