AWS KMS

خدمة إدارة مفاتيح مُدارة لتشفير البيانات مع تكامل عميق مع خدمات AWS. Managed key management service for data encryption with deep AWS integration.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Key Types Customer Managed Key (CMK) تحت تحكّمك، AWS Managed (aws/*)، AWS Owned (شفاف). Customer Managed Key (CMK) under your control, AWS Managed (aws/*), AWS Owned (transparent).
Symmetric vs Asymmetric Symmetric AES-256 للتشفير السريع، Asymmetric RSA/ECC للتواقيع والتوزيع. Symmetric AES-256 for fast encryption, Asymmetric RSA/ECC for signing and distribution.
Envelope Encryption Data Key مُشفّرة بـ CMK — استخدم DataKey للتشفير محليًا وEncryptedDataKey لحفظه مع البيانات. Data Key encrypted by CMK — use DataKey locally, store EncryptedDataKey with data.
Key Policy vs IAM Key Policy = السياسة الأساسية للمفتاح (مطلوب). IAM Policy تضيف صلاحيات للهويات. Key Policy = base key policy (required). IAM adds permissions for identities.
Grants صلاحيات مؤقّتة على مفتاح لخدمة أو مستخدم — تُلغى بسهولة. Temporary permissions on a key for a service/user — easily revocable.
Multi-Region Keys مفتاح أساسي + نسخ متماثلة في مناطق أخرى — نفس Key ID ومواد التشفير. Primary + replicas in other regions — same Key ID and key material.
Key Rotation Automatic Rotation سنويًا للـ CMK (symmetric فقط)، Manual لـ asymmetric. Annual automatic rotation for CMK (symmetric only), manual for asymmetric.
External / CloudHSM External = أنت تستورد مادة المفتاح، CloudHSM = HSM مخصّص مع FIPS 140-2 L3. External = you import key material; CloudHSM = dedicated HSM with FIPS 140-2 L3.

أوامر CLI الأساسية Essential CLI Commands

إنشاء مفتاح. Create key. 

aws kms create-key --description 'Acme App Key' --key-usage ENCRYPT_DECRYPT --key-spec SYMMETRIC_DEFAULT

تشفير نصّ قصير. Encrypt short data. 

aws kms encrypt --key-id alias/acme --plaintext fileb://secret.txt --output text --query CiphertextBlob

إنشاء Data Key. Generate Data Key. 

aws kms generate-data-key --key-id alias/acme --key-spec AES_256

إنشاء alias. Create alias. 

aws kms create-alias --alias-name alias/acme --target-key-id <KEY_ID>

تفعيل Rotation سنوي. Enable annual rotation. 

aws kms enable-key-rotation --key-id alias/acme

جدولة حذف مفتاح. Schedule key deletion. 

aws kms schedule-key-deletion --key-id <KEY_ID> --pending-window-in-days 7

نصائح للامتحان Exam Tips

Encrypt API يأخذ فقط 4 KB — استخدم DataKey + Envelope للبيانات الأكبر. Encrypt API takes only 4 KB — use DataKey + Envelope for larger data.
Key Policy مطلوبة؛ IAM وحده لا يكفي للوصول إلى مفتاح. Key Policy is required; IAM alone is not enough to access a key.
S3 SSE-KMS يضرب الأداء إذا رفعت ملايين الكائنات — فكّر في S3 Bucket Keys. S3 SSE-KMS hurts performance for millions of objects — consider S3 Bucket Keys.
Multi-Region Keys لها نفس Key ID في المناطق — نصّ مشفّر بمنطقة يُفكّ بأخرى. Multi-Region Keys share Key ID — encrypt in one region, decrypt in another.
CloudHSM للـ FIPS 140-2 L3 — KMS فقط L2. CloudHSM for FIPS 140-2 L3 — KMS is only L2.
