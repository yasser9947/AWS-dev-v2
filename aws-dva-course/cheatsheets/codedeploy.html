AWS CodeDeploy

خدمة نشر تُنسّق تحديث الكود على EC2/On-Prem/Lambda/ECS باستراتيجيات Canary/Linear/AllAtOnce مع hooks عبر appspec.yml. Deployment service orchestrating updates to EC2/On-Prem/Lambda/ECS with Canary/Linear/AllAtOnce strategies and appspec.yml hooks.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Application وحدة منطقية تحوي deployment groups؛ نوعها EC2/OnPrem, Lambda, أو ECS. Logical unit containing deployment groups; compute platform EC2/OnPrem, Lambda, or ECS.
Deployment Group مجموعة أهداف النشر (EC2 tags/ASG/Lambda function/ECS service). Set of targets (EC2 tags/ASG/Lambda function/ECS service).
appspec.yml (EC2) يحدّد files/permissions وhooks: ApplicationStop, BeforeInstall, AfterInstall, ApplicationStart, ValidateService. Defines files/permissions and hooks: ApplicationStop, BeforeInstall, AfterInstall, ApplicationStart, ValidateService.
appspec.yml (Lambda) يحدّد function versions وhooks: BeforeAllowTraffic, AfterAllowTraffic. Defines function versions and hooks: BeforeAllowTraffic, AfterAllowTraffic.
appspec.yml (ECS) يحدّد TaskDefinition/ContainerName وhooks: BeforeInstall, AfterInstall, AfterAllowTestTraffic, BeforeAllowTraffic, AfterAllowTraffic. Defines TaskDefinition/ContainerName with hooks: BeforeInstall, AfterInstall, AfterAllowTestTraffic, BeforeAllowTraffic, AfterAllowTraffic.
Deployment Config (EC2) AllAtOnce / HalfAtATime / OneAtATime أو مخصص (min healthy hosts). AllAtOnce / HalfAtATime / OneAtATime or custom (min healthy hosts).
Deployment Config (Lambda/ECS) Canary / Linear / AllAtOnce مع أمثلة Canary10Percent5Minutes و Linear10PercentEvery1Minute. Canary / Linear / AllAtOnce with presets like Canary10Percent5Minutes, Linear10PercentEvery1Minute.
Blue/Green طريقة نشر تبني بيئة جديدة وتحوّل الحركة إليها (ممكن لـ EC2/Lambda/ECS). Deployment type provisioning new environment and shifting traffic (EC2/Lambda/ECS).
CodeDeploy Agent خدمة تعمل على EC2/On-Prem لتلقّي تعليمات النشر. Daemon running on EC2/On-Prem to receive deployment instructions.

أوامر CLI الأساسية Essential CLI Commands

إنشاء تطبيق Lambda. Create Lambda application. 

aws deploy create-application --application-name my-app --compute-platform Lambda

إنشاء deployment group. Create deployment group. 

aws deploy create-deployment-group --application-name my-app --deployment-group-name prod --service-role-arn arn:... --deployment-config-name CodeDeployDefault.LambdaCanary10Percent5Minutes

بدء نشر. Create deployment. 

aws deploy create-deployment --application-name my-app --deployment-group-name prod --revision '{"revisionType":"S3","s3Location":{...}}'

إيقاف نشر ومعالجة rollback. Stop deployment and rollback. 

aws deploy stop-deployment --deployment-id d-123 --auto-rollback-enabled

حالة النشر. Get deployment status. 

aws deploy get-deployment --deployment-id d-123

نصائح للامتحان Exam Tips

Lambda deployments تستخدم Canary/Linear/AllAtOnce؛ EC2 تستخدم AllAtOnce/HalfAtATime/OneAtATime. Lambda uses Canary/Linear/AllAtOnce; EC2 uses AllAtOnce/HalfAtATime/OneAtATime.
Canary10Percent5Minutes يعني 10% أولاً، ثم 90% بعد 5 دقائق. Canary10Percent5Minutes: 10% first, then 90% after 5 minutes.
appspec hooks لـ EC2: ApplicationStop/BeforeInstall/AfterInstall/ApplicationStart/ValidateService (ترتيب مهم). EC2 hooks: ApplicationStop/BeforeInstall/AfterInstall/ApplicationStart/ValidateService (order matters).
ECS Blue/Green يتطلب ALB/NLB مع target groups اثنين (blue/green). ECS Blue/Green requires ALB/NLB with two target groups (blue/green).
Auto rollback يبدأ عند deployment failure أو تفعيل CloudWatch alarm محدد. Auto rollback triggers on deployment failure or specified CloudWatch alarm.
