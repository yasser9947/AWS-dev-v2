Amazon Cognito

مصادقة وترخيص للتطبيقات الويب والموبايل عبر User Pools و Identity Pools. Auth and authorization for web/mobile apps via User Pools and Identity Pools.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
User Pool vs Identity Pool User Pool = مصادقة (Authentication) تُصدر JWT. Identity Pool = ترخيص (Authorization) يعطي بيانات اعتماد AWS. User Pool = Authentication (returns JWTs). Identity Pool = Authorization (returns AWS creds).
3 JWT Tokens ID Token (هوية)، Access Token (صلاحيات API)، Refresh Token (تجديد الجلسة). ID Token (identity), Access Token (API permissions), Refresh Token (renew session).
Federated Identity تسجيل عبر Google، Facebook، Apple، SAML، أو IdP مخصّص. Sign-in via Google, Facebook, Apple, SAML, or custom IdP.
Lambda Triggers PreSignup، PostConfirmation، PreAuthentication، PreTokenGeneration، CustomMessage لتخصيص التدفّق. PreSignup, PostConfirmation, PreAuthentication, PreTokenGeneration, CustomMessage customize flows.
OAuth2 Flows Authorization Code + PKCE (الموصى به)، Implicit (لا يُنصح)، Client Credentials (خادم-خادم). Authorization Code + PKCE (recommended), Implicit (discouraged), Client Credentials (server-to-server).
MFA & Adaptive Auth MFA إلزاميّ أو اختياريّ (SMS/TOTP)، وAdaptive تقيّم المخاطر على كل محاولة دخول. Mandatory or optional MFA (SMS/TOTP); Adaptive assesses risk per login attempt.
Identity Pool Roles دور للمصادَقين (Auth) ودور للضيوف (Unauth) يُعطي بيانات AWS عبر STS. Auth + Unauth role hand out AWS creds via STS.
Fine-Grained S3 via IAM استخدم ${cognito-identity.amazonaws.com:sub} في سياسة S3 لعزل ملفات كل مستخدم. Use ${cognito-identity.amazonaws.com:sub} in S3 policy to isolate each user's files.

أوامر CLI الأساسية Essential CLI Commands

إنشاء User Pool. Create a User Pool. 

aws cognito-idp create-user-pool --pool-name AcmeUsers --policies file://pwd-policy.json

إنشاء App Client. Create App Client. 

aws cognito-idp create-user-pool-client --user-pool-id us-east-1_XXX --client-name web --generate-secret

تسجيل مستخدم جديد. Sign up a user. 

aws cognito-idp sign-up --client-id abc --username yasir@acme.com --password Secret!1

تأكيد تسجيل (رمز الإيميل). Confirm signup. 

aws cognito-idp confirm-sign-up --client-id abc --username yasir@acme.com --confirmation-code 123456

مصادقة المستخدم. Authenticate user. 

aws cognito-idp initiate-auth --auth-flow USER_PASSWORD_AUTH --client-id abc --auth-parameters USERNAME=yasir,PASSWORD=Secret!1

نصائح للامتحان Exam Tips

User Pool = JWT. Identity Pool = AWS Credentials. User Pool = JWT. Identity Pool = AWS Credentials.
استخدم Authorization Code + PKCE دائمًا للـ SPA. Always use Authorization Code + PKCE for SPAs.
API Gateway يدعم Cognito Authorizer مباشرة عبر الـ ID Token. API Gateway supports Cognito Authorizer directly via ID Token.
PreTokenGeneration Lambda يُضيف claims مخصّصة للـ JWT. PreTokenGeneration Lambda adds custom claims to the JWT.
Identity Pool وحده لا يصادق — يحتاج مصدر مصادقة (User Pool أو خارجي). Identity Pool alone doesn't authenticate — needs an auth source (User Pool or external).
