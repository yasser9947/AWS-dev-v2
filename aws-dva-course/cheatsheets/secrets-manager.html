ملخّص سريع Cheatsheet

AWS Secrets Manager

إدارة الأسرار بتدوير تلقائي وتكامل أصلي مع قواعد البيانات. Secret management with automatic rotation and native DB integration.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Secret Structure اسم + نسخة + JSON (أزواج مفتاح/قيمة) — مشفّر بـ KMS. Name + version + JSON (key-value pairs) — encrypted via KMS.
Automatic Rotation Lambda Rotation Function تُحدّث السر دوريًا (كل 30-365 يوم). قوالب جاهزة لـ RDS/Aurora/DocumentDB/Redshift. Lambda Rotation Function rotates periodically (30–365 days). Built-in templates for RDS/Aurora/DocumentDB/Redshift.
4 Rotation Stages AWSCURRENT (الحالي)، AWSPENDING (قيد التدوير)، AWSPREVIOUS (السابق)، اختياري staging labels. AWSCURRENT, AWSPENDING, AWSPREVIOUS, optional custom staging labels.
Cross-Account & Replication Resource Policy للمشاركة بين الحسابات، Replication إلى مناطق أخرى. Resource Policy for cross-account sharing, Replication to other regions.
Versioning كل تحديث يُنتج version جديد (UUID) — يمكن استرجاع أي نسخة. Each update = new version (UUID) — retrievable.
Secrets vs Parameter Store Secrets Manager = rotation مُدمج + أعلى تكلفة. Parameter Store = أرخص بدون rotation. Secrets Manager = built-in rotation + higher cost. Parameter Store = cheaper, no rotation.

أوامر CLI الأساسية Essential CLI Commands

إنشاء سر. Create secret. 

aws secretsmanager create-secret --name prod/db/mysql --secret-string '{"user":"acme","pass":"S3cr3t!"}'

قراءة سر. Get secret. 

aws secretsmanager get-secret-value --secret-id prod/db/mysql --query SecretString --output text

تحديث سر. Update secret. 

aws secretsmanager update-secret --secret-id prod/db/mysql --secret-string '{...}'

تفعيل Rotation تلقائي. Enable rotation. 

aws secretsmanager rotate-secret --secret-id prod/db/mysql --rotation-lambda-arn arn:... --rotation-rules AutomaticallyAfterDays=30

جدولة حذف. Schedule deletion. 

aws secretsmanager delete-secret --secret-id prod/db/mysql --recovery-window-in-days 7

نصائح للامتحان Exam Tips

Rotation = سمة Secrets Manager الرئيسية (Parameter Store لا يدعمها أصلاً). Rotation is Secrets Manager's killer feature — Parameter Store can't do it natively.
Lambda Rotation Function = نقطة تفاعل الامتحان الأساسية. Lambda Rotation Function is a common exam topic.
RDS Managed Password يستخدم Secrets Manager خلف الكواليس. RDS Managed Password uses Secrets Manager under the hood.
Resource Policy = مشاركة عبر الحسابات بدون IAM Role. Resource Policy = cross-account without IAM Role.
Recovery window = مانع حماية من الحذف الخاطئ. Recovery window = accidental-delete protection.
