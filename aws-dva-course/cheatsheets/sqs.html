ملخّص سريع Cheatsheet

Amazon SQS

طابور رسائل مُدار بدون خوادم يفصل بين المُرسِل والمُستقبِل ويدعم Standard و FIFO مع Dead-Letter Queues. Managed serverless message queue that decouples producer and consumer; supports Standard and FIFO with DLQs.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Standard vs FIFO Standard: at-least-once وترتيب غير مضمون. FIFO: ترتيب مضمون وexactly-once بمعدّل أقلّ. Standard: at-least-once, best-effort order. FIFO: exactly-once, strict ordering, lower throughput.
Visibility Timeout مدّة إخفاء الرسالة بعد استلامها (افتراضي 30 ثانية، أقصى 12 ساعة). Time a message is hidden after receive (default 30s, max 12h).
Long Polling ReceiveMessage ينتظر حتى 20 ثانية لتقليل الطلبات الفارغة. ReceiveMessage waits up to 20s to reduce empty responses.
Message Retention من 1 دقيقة إلى 14 يومًا (افتراضي 4 أيام). From 1 minute to 14 days (default 4 days).
Dead-Letter Queue طابور يستقبل الرسائل التي فشل معالجتها بعد maxReceiveCount. Queue that captures messages exceeding maxReceiveCount.
FIFO Groups MessageGroupId يضمن ترتيب كل مجموعة؛ MessageDeduplicationId لمنع التكرار. MessageGroupId preserves order per group; MessageDeduplicationId deduplicates.
Delay Queue DelaySeconds يؤخّر الرسالة حتى 15 دقيقة قبل الظهور. DelaySeconds delays a message up to 15 min before becoming visible.
Encryption SQS-managed (SSE-SQS) أو KMS. SSE-SQS or KMS-based encryption at rest.

أوامر CLI الأساسية Essential CLI Commands

إنشاء طابور Standard. Create a standard queue. 

aws sqs create-queue --queue-name orders --attributes VisibilityTimeout=60,MessageRetentionPeriod=345600

إنشاء طابور FIFO. Create a FIFO queue. 

aws sqs create-queue --queue-name orders.fifo --attributes FifoQueue=true,ContentBasedDeduplication=true

إرسال رسالة إلى Standard. Send a message to a Standard queue. 

aws sqs send-message --queue-url https://sqs.us-east-1.amazonaws.com/111/orders --message-body '{"id":42}'

إرسال رسالة FIFO مع GroupId. Send a FIFO message with GroupId. 

aws sqs send-message --queue-url ...orders.fifo --message-body '{"id":42}' --message-group-id customerA --message-deduplication-id 42

استلام رسائل بـ Long Polling. Receive with long polling. 

aws sqs receive-message --queue-url ... --max-number-of-messages 10 --wait-time-seconds 20

ضبط DLQ. Configure a DLQ redrive policy. 

aws sqs set-queue-attributes --queue-url ...orders --attributes RedrivePolicy='{"deadLetterTargetArn":"arn:aws:sqs:us-east-1:111:orders-dlq","maxReceiveCount":"5"}'

متى تستخدم Amazon SQS؟ When to use Amazon SQS

فصل أجزاء النظام لامتصاص زيادات الحمل. Decouple components to absorb traffic spikes.

SQS Standard

تنفيذ العمليات المُطلوبة بترتيب واحد تلو الآخر. Process actions strictly in order, once.

SQS FIFO

تأخير تنفيذ مهمّة لعدّة دقائق. Delay a task for several minutes.

SQS Delay Queue

رصد الرسائل السامة التي فشلت في المعالجة. Track poison-pill messages that failed processing.

SQS DLQ

نصائح للامتحان Exam Tips

Standard at-least-once قد يُسلّم الرسالة أكثر من مرّة؛ اجعل المعالجة idempotent. Standard is at-least-once and may duplicate; make processing idempotent.
Visibility Timeout يجب أن يتجاوز زمن معالجة العامل لتفادي التكرار. Visibility timeout must exceed worker processing time to avoid duplicates.
Long Polling (20s) يُوصى به افتراضيًا لتقليل استدعاءات فارغة. Long polling (20s) is recommended by default to reduce empty calls.
FIFO تتطلّب MessageGroupId وتوفّر exactly-once ضمن مدة إلغاء التكرار (5 دقائق). FIFO requires MessageGroupId and provides exactly-once within a 5-min dedup window.
DLQ لا تُنشأ تلقائيًا؛ عرّف RedrivePolicy مع maxReceiveCount. DLQ isn’t automatic — define a RedrivePolicy with maxReceiveCount.
