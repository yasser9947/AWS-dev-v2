المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Invocation Models Sync (API Gateway، ALB)، Async (S3، SNS)، Event Source Mapping (SQS، Kinesis، DynamoDB Streams). Sync (API Gateway, ALB), Async (S3, SNS), Event Source Mapping (SQS, Kinesis, DynamoDB Streams).
Execution Role IAM Role تُعطى للدالة للوصول إلى خدمات AWS — لا تُستخدم Access Keys. IAM Role granting function AWS access — never hardcode keys.
Memory & CPU تخصيص الذاكرة يحدّد CPU تلقائيًا (1792 MB = 1 vCPU كامل). Memory allocation implicitly sets CPU (1792 MB = 1 full vCPU).
Cold Start بدء تشغيل بارد عند أوّل طلب أو بعد عدم نشاط — Provisioned Concurrency يلغيه. First-request warmup — Provisioned Concurrency eliminates it.
Layers طبقات مشتركة للمكتبات (حتى 5 لكل دالة) لتقليل حجم الحزمة وإعادة الاستخدام. Shared library layers (up to 5 per function) to reduce package size.
Destinations & DLQ Async: Destinations (SQS/SNS/Lambda/EventBridge) للنجاح/الفشل، أو DLQ التقليدية. Async: Destinations (SQS/SNS/Lambda/EventBridge) for success/failure, or legacy DLQ.
VPC Integration الدالة تعمل داخل VPC عبر ENI — يحتاج NAT Gateway للإنترنت. Function runs inside VPC via ENI — needs NAT Gateway for internet.
Versions & Aliases Version = لقطة ثابتة من الكود. Alias = مؤشّر قابل للتحويل (blue/green، canary). Version = immutable snapshot. Alias = pointer (blue/green, canary).

أوامر CLI الأساسية Essential CLI Commands

إنشاء دالة. Create function. 

aws lambda create-function --function-name acme-api --runtime java17 --role arn:aws:iam::111:role/exec --handler com.acme.Handler --zip-file fileb://fn.zip

تحديث الكود. Update code. 

aws lambda update-function-code --function-name acme-api --zip-file fileb://fn.zip --publish

استدعاء الدالة. Invoke function. 

aws lambda invoke --function-name acme-api --payload '{"id":1}' --cli-binary-format raw-in-base64-out out.json

حجز Provisioned Concurrency. Set Provisioned Concurrency. 

aws lambda put-provisioned-concurrency-config --function-name acme-api --qualifier PROD --provisioned-concurrent-executions 50

إنشاء Alias. Create alias. 

aws lambda create-alias --function-name acme-api --name PROD --function-version 12

متى تستخدم AWS Lambda؟ When to use AWS Lambda

API REST/GraphQL خلف API Gateway. REST/GraphQL API behind API Gateway.

Lambda (Sync invocation)

معالجة ملفات عند رفعها إلى S3. Process files on S3 upload.

Lambda (Async from S3 event)

استهلاك من SQS أو Kinesis. Consume from SQS or Kinesis.

Lambda Event Source Mapping

مهام طويلة > 15 دقيقة. Long-running > 15 min.

Step Functions / Fargate / Batch

زمن استجابة منخفض جدًا (< 10 ms). Ultra-low latency (< 10 ms).

نصائح للامتحان Exam Tips

Java + cold start = أسوأ مزيج — استخدم Provisioned Concurrency أو SnapStart. Java + cold start = worst combo — use Provisioned Concurrency or SnapStart.
Reserved Concurrency يحمي خدمات downstream من فيضان الدالة. Reserved Concurrency protects downstream from function flood.
Lambda في VPC بدون NAT = لا إنترنت. Lambda in VPC without NAT = no internet.
Event Source Mapping يقرأ من SQS/Kinesis — Lambda نفسها لا تحتاج IAM للقراءة. ESM pulls from SQS/Kinesis — Lambda doesn't need IAM to read.
استخدم Aliases + CodeDeploy لنشر Canary/Linear بأمان. Use Aliases + CodeDeploy for safe Canary/Linear deploys.
