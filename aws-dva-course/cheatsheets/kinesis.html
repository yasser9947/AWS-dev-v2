Amazon Kinesis

منصّة بيانات متدفّقة لحظيّة: Data Streams للتدفق الخام، Firehose للتحميل المُدار، وManaged Flink للتحليل الفوري. Real-time streaming data platform: Data Streams for raw ingest, Firehose for managed delivery, Managed Flink for real-time analytics.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Data Streams تدفّق بيانات قابل لإعادة التشغيل، احتفاظ 24 ساعة حتى 365 يوم. Replayable data stream with 24h to 365d retention.
Shard وحدة مقياس: 1 MB/s write, 2 MB/s read, 1000 records/s في وضع Provisioned. Scaling unit (Provisioned): 1 MB/s write, 2 MB/s read, 1000 records/s.
On-Demand mode مقياس تلقائي بدون إدارة shards؛ يبدأ 4 MB/s write ويتضاعف تلقائياً. Auto-scaling without shard management; starts 4 MB/s write, auto-doubles.
Partition Key يحدد إلى أي shard يذهب الريكورد؛ يؤثّر على التوزيع (hot shards). Determines shard assignment; impacts distribution (hot shards).
Consumers Classic (shared 2 MB/s) أو Enhanced Fan-Out (EFO) مخصص 2 MB/s لكل consumer. Classic (shared 2 MB/s) or Enhanced Fan-Out (EFO) 2 MB/s per consumer.
KPL / KCL مكتبة المنتج (Kinesis Producer Library) مع batching، ومكتبة المستهلك (KCL) لتوزيع العمل. Kinesis Producer Library (batching) and Kinesis Client Library (worker coordination).
Firehose تسليم مُدار إلى S3/Redshift/OpenSearch/Splunk مع buffering وتحويل. Managed delivery to S3/Redshift/OpenSearch/Splunk with buffering and transform.
Managed Service for Apache Flink تحليل تدفّقي عبر SQL أو Flink لاحتساب مقاييس لحظية. Real-time stream analytics via SQL or Flink for live metrics.

أوامر CLI الأساسية Essential CLI Commands

إنشاء تدفّق بيانات بوضع On-Demand. Create on-demand data stream. 

aws kinesis create-stream --stream-name orders --stream-mode-details StreamMode=ON_DEMAND

كتابة ريكورد. Put a record. 

aws kinesis put-record --stream-name orders --partition-key user-1 --data $(echo -n '{"id":1}' | base64)

تسجيل EFO consumer. Register an EFO consumer. 

aws kinesis register-stream-consumer --stream-arn arn:aws:kinesis:...:orders --consumer-name analytics

إنشاء Firehose إلى S3. Create Firehose delivery to S3. 

aws firehose create-delivery-stream --delivery-stream-name to-s3 --s3-destination-configuration RoleARN=...,BucketARN=arn:aws:s3:::logs

قراءة shard iterator. Read via shard iterator. 

aws kinesis get-shard-iterator --stream-name orders --shard-id shardId-0 --shard-iterator-type TRIM_HORIZON

نصائح للامتحان Exam Tips

Firehose = near-real-time بحدّ أدنى 60 ثانية buffer؛ ليس لحظياً حقيقياً. Firehose is near-real-time with 60 s min buffer — not truly real-time.
احتفاظ Data Streams الافتراضي 24 ساعة؛ زد حتى 365 يوم لإعادة المعالجة. Data Streams default retention is 24 h; extend to 365 days for reprocessing.
Hot shard = سوء اختيار partition key؛ استخدم UUID أو مفتاح موزّع. Hot shard = bad partition key; pick UUID or well-distributed key.
EFO يعطي 2 MB/s مخصصة لكل consumer مع latency ~70 ms بدلاً من 200 ms. EFO gives dedicated 2 MB/s per consumer with ~70 ms latency vs 200 ms.
Firehose يدعم تحويل Lambda وتحويل Parquet/ORC قبل الكتابة إلى S3. Firehose supports Lambda transforms and Parquet/ORC conversion before S3 write.
