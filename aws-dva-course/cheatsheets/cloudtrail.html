AWS CloudTrail

سجل مراجعة (Audit) لاستدعاءات AWS API: Management/Data/Insights events، يسلّم إلى S3 وCloudWatch Logs. AWS API audit log: Management/Data/Insights events delivered to S3 and CloudWatch Logs for compliance and forensics.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Management Events عمليات التحكم (CreateBucket, RunInstances)؛ مفعّلة افتراضياً 90 يوم عبر Event history. Control-plane ops (CreateBucket, RunInstances); on by default for 90 days via Event history.
Data Events قراءة/كتابة على مستوى البيانات (S3 object-level, Lambda Invoke)؛ غير مفعّلة افتراضياً. Data-plane read/write (S3 object-level, Lambda Invoke); off by default.
Insights Events يكشف شذوذ في معدّل API calls (ترخيص إضافي). Detects anomalies in API call rates (additional charge).
Trail يُسلّم الأحداث إلى S3 (دائم) و/أو CloudWatch Logs؛ يشمل region واحد أو Multi-Region. Delivers events to S3 (persistent) and/or CloudWatch Logs; single-region or multi-region.
Organization Trail Trail في حساب الإدارة يجمع أحداث كل الحسابات في منظمة AWS Organizations. Management-account trail aggregating events from all accounts in AWS Organizations.
CloudTrail Lake مخزن مُدار للاستعلام عبر SQL مباشرة على الأحداث (احتفاظ حتى 10 سنوات). Managed data store to SQL-query events directly (up to 10-year retention).
Log File Integrity digest files موقّعة بـ SHA-256 + RSA للتحقق من عدم العبث. Digest files signed with SHA-256 + RSA to verify tamper-free logs.
Event delivery latency Management events تصل عادة خلال 15 دقيقة. Management events typically delivered within 15 minutes.

أوامر CLI الأساسية Essential CLI Commands

إنشاء trail متعدد المناطق. Create multi-region trail. 

aws cloudtrail create-trail --name my-trail --s3-bucket-name my-ct-bucket --is-multi-region-trail

بدء تسجيل trail. Start trail logging. 

aws cloudtrail start-logging --name my-trail

تفعيل data events على S3. Enable S3 data events. 

aws cloudtrail put-event-selectors --trail-name my-trail --event-selectors 'ReadWriteType=All,DataResources=[{Type=AWS::S3::Object,Values=[arn:aws:s3:::my-bucket/]}]'

البحث في event history (90 يوم). Lookup events in history. 

aws cloudtrail lookup-events --lookup-attributes AttributeKey=EventName,AttributeValue=RunInstances

تشغيل استعلام Lake. Run a Lake query. 

aws cloudtrail start-query --query-statement 'SELECT eventName, count(*) FROM abc GROUP BY eventName' --query-alias cnt

نصائح للامتحان Exam Tips

Event history في الكونسول 90 يوم فقط ومجاني؛ للاحتفاظ الأطول أنشئ Trail إلى S3. Console Event history is 90 days and free; for longer retention create a Trail to S3.
Data events (S3 object / Lambda Invoke) مدفوعة ومغلقة افتراضياً — فعّلها صراحة. Data events (S3 object / Lambda Invoke) are paid and off by default — enable explicitly.
Multi-Region Trail يحتفظ بأحداث جميع regions؛ Organization Trail لكل حسابات AWS Organizations. Multi-Region Trail covers all regions; Organization Trail covers all AWS Organizations accounts.
Log File Integrity Validation يكتشف أي تعديل باستخدام digest files (SHA-256 + RSA). Log File Integrity Validation detects tampering via digest files (SHA-256 + RSA).
للتنبيه الفوري: Trail → CloudWatch Logs → Metric Filter → Alarm → SNS. For near-real-time alerts: Trail → CloudWatch Logs → Metric Filter → Alarm → SNS.
