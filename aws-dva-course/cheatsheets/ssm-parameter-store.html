SSM Parameter Store

تخزين الإعدادات والأسرار بطبقتين — Standard مجّانية و Advanced مع خصائص إضافية. Configuration + secret storage with Standard (free) and Advanced tiers.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Parameter Types String، StringList، SecureString (مشفّر بـ KMS). String, StringList, SecureString (KMS-encrypted).
Hierarchy مسار شجري مثل /acme/prod/db/host يسمح بقراءة فرع كامل بطلب واحد. Tree path like /acme/prod/db/host — read a whole branch in one call.
Standard vs Advanced Standard: مجّاني، 4KB، 10k params. Advanced: $0.05/param، 8KB، سياسات، 100k params. Standard: free, 4KB, 10k params. Advanced: $0.05/param, 8KB, policies, 100k params.
Policies (Advanced) Expiration، ExpirationNotification، NoChangeNotification للحصول على أحداث EventBridge. Expiration, ExpirationNotification, NoChangeNotification — fires EventBridge events.
Versioning كل تحديث يُنشئ version جديد — يمكن الرجوع والإشارة إلى version محدّد. Each update creates a new version — rollback + reference specific versions.
Public Parameters AWS ينشر parameters عامّة مثل /aws/service/ami-windows-latest/* للـ AMIs. AWS publishes public params like /aws/service/ami-windows-latest/* for AMIs.
IAM Integration ssm:GetParameter* + kms:Decrypt للـ SecureString — لا يحتاج Resource Policy. ssm:GetParameter* + kms:Decrypt for SecureString — no resource policy needed.

أوامر CLI الأساسية Essential CLI Commands

كتابة parameter عادي. Put a standard parameter. 

aws ssm put-parameter --name /acme/prod/api-url --value https://api.acme.com --type String

كتابة SecureString بمفتاح KMS مخصّص. Put SecureString with custom KMS key. 

aws ssm put-parameter --name /acme/prod/api-key --value XYZ --type SecureString --key-id alias/acme

قراءة parameter مع فكّ تشفير. Get with decryption. 

aws ssm get-parameter --name /acme/prod/api-key --with-decryption --query Parameter.Value --output text

قراءة فرع كامل. Get whole path. 

aws ssm get-parameters-by-path --path /acme/prod --recursive --with-decryption

عرض تاريخ parameter. Show parameter history. 

aws ssm get-parameter-history --name /acme/prod/api-key

وضع سياسة انتهاء صلاحية. Apply expiration policy (Advanced). 

aws ssm put-parameter --name /acme/tmp/key --value v --type String --tier Advanced --policies '[{"Type":"Expiration","Version":"1.0","Attributes":{"Timestamp":"2030-01-01T00:00:00.000Z"}}]'

Advanced + NoChangeNotification policy

نصائح للامتحان Exam Tips

SecureString يستخدم KMS — تحتاج صلاحية kms:Decrypt. SecureString uses KMS — need kms:Decrypt permission.
Parameter Store أرخص بكثير من Secrets Manager — لكن بدون rotation. Parameter Store is much cheaper, but no native rotation.
Hierarchy = organize parameters منطقيًا وقراءة شجرة بـ call واحد. Hierarchy = logical organization + one-call tree reads.
Public parameters لمعرفة أحدث AMI ID بدون hardcoding. Public parameters fetch latest AMI ID without hardcoding.
Advanced tier فقط يدعم Policies وExpiration. Only Advanced tier supports Policies + Expiration.
