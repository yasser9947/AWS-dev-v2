AWS CloudFormation

Infrastructure as Code مُدار: يصف الموارد في قوالب JSON/YAML وينفّذها كـ Stack مع قدرات Drift Detection وChange Sets. Managed Infrastructure as Code: describe resources in JSON/YAML templates and deploy as Stacks with Change Sets and Drift Detection.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Template ملف JSON/YAML يصف Parameters, Resources, Outputs, Mappings, Conditions. JSON/YAML file describing Parameters, Resources, Outputs, Mappings, Conditions.
Stack تجميعة موارد مُنشأة من قالب؛ تُحدَّث أو تُحذَف ككتلة واحدة. Collection of resources from a template managed as a unit.
Change Set معاينة التغييرات قبل تنفيذ update لتجنّب المفاجآت. Preview changes before executing update to avoid surprises.
Stack Policy JSON لحماية موارد حساسة من التحديث/الحذف غير المقصود. JSON protecting sensitive resources from accidental update/delete.
Nested / Cross-Stack Nested = طفل داخل والد عبر AWS::CloudFormation::Stack؛ Cross-Stack = Export/ImportValue. Nested = child resource via AWS::CloudFormation::Stack; Cross-Stack = Export/ImportValue.
StackSets نشر نفس القالب عبر حسابات ومناطق متعددة. Deploy the same template across multiple accounts and regions.
Drift Detection يكتشف التغييرات اليدوية خارج CloudFormation. Detects manual changes made outside CloudFormation.
DeletionPolicy / UpdateReplacePolicy Retain/Snapshot/Delete لحماية البيانات عند الحذف أو الاستبدال. Retain/Snapshot/Delete to protect data on delete or replace.
Intrinsic Functions Ref, Fn::GetAtt, Fn::Sub, Fn::Join, Fn::ImportValue, Fn::If, Fn::FindInMap. Ref, Fn::GetAtt, Fn::Sub, Fn::Join, Fn::ImportValue, Fn::If, Fn::FindInMap.

أوامر CLI الأساسية Essential CLI Commands

إنشاء stack من قالب. Create stack from template. 

aws cloudformation create-stack --stack-name prod --template-body file://tmpl.yaml --parameters ParameterKey=Env,ParameterValue=prod --capabilities CAPABILITY_NAMED_IAM

معاينة تغيير قبل التنفيذ. Preview a change before executing. 

aws cloudformation create-change-set --stack-name prod --change-set-name v2 --template-body file://tmpl.yaml

تحديث stack. Update stack. 

aws cloudformation update-stack --stack-name prod --template-body file://tmpl.yaml --capabilities CAPABILITY_IAM

تحقّق من القالب. Validate template. 

aws cloudformation validate-template --template-body file://tmpl.yaml

كشف الانجراف. Detect drift. 

aws cloudformation detect-stack-drift --stack-name prod

حذف stack. Delete stack. 

aws cloudformation delete-stack --stack-name prod

نصائح للامتحان Exam Tips

Ref على resource = ID؛ على parameter = القيمة. GetAtt = سمة معيّنة (مثل Arn). Ref on resource = ID; on parameter = value. GetAtt = specific attribute (e.g. Arn).
Fn::Sub أبسط وأوضح من Fn::Join عند بناء سلاسل تحتوي على متغيرات. Fn::Sub is cleaner than Fn::Join when interpolating variables.
CAPABILITY_IAM/CAPABILITY_NAMED_IAM مطلوب لإنشاء IAM resources؛ CAPABILITY_AUTO_EXPAND للـ macros/SAM. CAPABILITY_IAM/NAMED_IAM required for IAM resources; CAPABILITY_AUTO_EXPAND for macros/SAM.
DeletionPolicy: Retain يُحتَفَظ بالمورد حتى بعد حذف الـ stack — مفيد للبيانات. DeletionPolicy: Retain keeps resource even after stack deletion — useful for data.
Export/Import مقيّد بنفس region؛ لعبور regions استخدم StackSets أو SSM Parameter Store. Export/Import is region-scoped; cross-region needs StackSets or SSM Parameter Store.
