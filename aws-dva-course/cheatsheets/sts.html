AWS STS

خدمة إصدار بيانات اعتماد مؤقتة للأدوار والهويات الفيدرالية. Temporary credential service for roles and federated identities.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
AssumeRole تحمّل دور لحصول على بيانات اعتماد مؤقّتة (حدّ افتراضي ساعة، حتى 12 ساعة). Assume a role to obtain temporary credentials (default 1h, up to 12h).
AssumeRoleWithSAML تبادل SAML Assertion من IdP خارجي بصلاحيات AWS مؤقّتة. Exchange SAML assertion from an external IdP for temporary AWS credentials.
AssumeRoleWithWebIdentity تبادل OIDC token (Google/Cognito/Facebook) ببيانات اعتماد AWS. Exchange OIDC token (Google/Cognito/Facebook) for AWS credentials.
GetSessionToken للمستخدمين الحاليين يحتاجون MFA لعمل طلبات محدودة. For existing users needing MFA-protected short-term credentials.
GetFederationToken يصدر بيانات اعتماد لمستخدمين فيدراليين مخصّصين (اسم جلسة محدّد). Issues credentials for custom federated users (named session).
Session Policy سياسة تُطبَّق على الجلسة لتضييق صلاحيات الدور (لا توسّعها). Inline policy applied to a session to narrow (not expand) role permissions.
External ID معرّف مشترك لمنع هجوم الـ Confused Deputy في حالات الوصول بين الحسابات. Shared ID preventing Confused Deputy attack in cross-account access.
Role Chaining تحمّل دور من دور آخر — الحدّ الأقصى للعمر ينخفض لساعة. Role assumes another role — max duration drops to 1 hour.

أوامر CLI الأساسية Essential CLI Commands

تحمّل دور من CLI. Assume a role via CLI. 

aws sts assume-role --role-arn arn:aws:iam::222:role/CrossAcct --role-session-name yasir

تحمّل دور مع MFA. Assume role with MFA. 

aws sts assume-role --role-arn arn:aws:iam::111:role/AdminMFA --serial-number arn:aws:iam::111:mfa/yasir --token-code 123456

التحقّق من الهوية الحالية. Check caller identity. 

aws sts get-caller-identity

تحمّل دور مع Session Policy. Assume role with session policy. 

aws sts assume-role --role-arn arn:aws:iam::111:role/Dev --role-session-name restricted --policy file://session-policy.json

تحمّل دور عبر Web Identity. AssumeRoleWithWebIdentity. 

aws sts assume-role-with-web-identity --role-arn arn:aws:iam::111:role/Web --role-session-name s1 --web-identity-token $TOKEN
