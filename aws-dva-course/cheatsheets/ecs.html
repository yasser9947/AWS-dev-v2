Amazon ECS

منصّة تنسيق حاويات مُدارة بالكامل تدعم EC2 Launch Type و Fargate. Fully-managed container orchestration supporting EC2 and Fargate launch types.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Cluster / Service / Task Cluster = مجموعة حاسوبية، Service = مجموعة Tasks دائمة، Task = تعريف تشغيل حاوية. Cluster = compute pool, Service = long-running Task group, Task = container run definition.
Task Definition JSON يصف الحاوية (image، ports، env، resources). يُنشر بإصداراتٍ محدّثة (revision). JSON describing container (image, ports, env, resources). Published in revisions.
Launch Types EC2 (تتحكّم بالسيرفرات)، Fargate (serverless)، External (ECS Anywhere). EC2 (you manage servers), Fargate (serverless), External (ECS Anywhere).
Task Role vs Execution Role Task Role = صلاحيات التطبيق داخل الحاوية. Execution Role = سحب الصور وكتابة سجلات. Task Role = app permissions inside container. Execution Role = pull images, write logs.
Service Auto Scaling توسيع تلقائي على Target Tracking / Step Scaling / Scheduled بناء على CPU أو ALB requests. Target Tracking / Step / Scheduled based on CPU or ALB requests.
Load Balancing ALB (HTTP)، NLB (TCP)، CLB (قديم) — ALB يدعم Dynamic Port Mapping مع EC2. ALB (HTTP), NLB (TCP), CLB (legacy) — ALB supports dynamic port mapping on EC2.
Service Discovery تكامل مع Route 53 (CloudMap) لإعطاء اسم DNS ثابت لكل خدمة. Integrates with Route 53 (CloudMap) giving each service a stable DNS name.
ECS Exec تنفيذ أوامر shell داخل الحاوية المُشغّلة عبر SSM بدون SSH. Exec shell commands inside a running task via SSM (no SSH).

أوامر CLI الأساسية Essential CLI Commands

إنشاء cluster. Create cluster. 

aws ecs create-cluster --cluster-name acme-prod

تسجيل Task Definition. Register Task Definition. 

aws ecs register-task-definition --cli-input-json file://td.json

إنشاء service. Create service. 

aws ecs create-service --cluster acme-prod --service-name web --task-definition web:12 --desired-count 3

تحديث service لإصدار جديد. Update service to new revision. 

aws ecs update-service --cluster acme-prod --service web --task-definition web:13 --force-new-deployment

تنفيذ أمر داخل task. Exec into task. 

aws ecs execute-command --cluster acme-prod --task arn:... --container web --interactive --command /bin/sh

نصائح للامتحان Exam Tips

Task Role ≠ Execution Role — فرّق بينهما في الامتحان. Task Role ≠ Execution Role — know the difference.
Fargate لا يدعم Placement Strategies — ECS على EC2 فقط. Placement Strategies are EC2-only, not Fargate.
ALB + Dynamic Port Mapping = تشغيل tasks متعدّدة على نفس الـ EC2. ALB + Dynamic Port Mapping = multiple tasks on same EC2.
FARGATE_SPOT = توفير حتى 70% لأعباء قابلة للمقاطعة. FARGATE_SPOT = up to 70% off for interruptible workloads.
ECS Exec بديل آمن للـ SSH — لا يحتاج bastion. ECS Exec = secure SSH alternative, no bastion needed.
