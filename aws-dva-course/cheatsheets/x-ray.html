AWS X-Ray

خدمة Distributed Tracing تُظهر خدمة-خدمة كخريطة (Service Map) مع segments وsubsegments لتشخيص الكمون والأخطاء. Distributed tracing service rendering service-to-service calls as a Service Map with segments/subsegments to diagnose latency and errors.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Trace مسار الطلب عبر عدة خدمات، مُعرَّف بواسطة Trace ID موحّد. End-to-end request path through services identified by a Trace ID.
Segment عمل خدمة واحدة (Lambda/EC2/ECS) ضمن trace. Work done by a single service (Lambda/EC2/ECS) within a trace.
Subsegment عملية داخلية: DB call, HTTP, custom timing. Internal operation: DB call, HTTP, or custom timing block.
Service Map تصوّر بصري للعلاقات بين الخدمات مع latency/errors. Visual representation of service relationships with latency/errors.
Sampling rules تحدد معدّل جمع traces لتقليل التكلفة (default: 1 req/s + 5%). Control trace sampling rate to save cost (default: 1 req/s + 5%).
Annotations vs Metadata Annotations = key/value مفهرسة للبحث؛ Metadata = بيانات إضافية غير مفهرسة. Annotations = indexed key/value for filtering; Metadata = non-indexed extra data.
X-Ray Daemon يستقبل UDP:2000 من SDK ويرسل segments إلى X-Ray API. Listens on UDP:2000 from SDK and forwards segments to X-Ray API.
SDKs / Active Tracing Lambda Active Tracing يرسل segments تلقائياً؛ SDK متاح لعدة لغات. Lambda Active Tracing auto-sends segments; SDKs available in multiple languages.

أوامر CLI الأساسية Essential CLI Commands

استرجاع trace بالمُعرّف. Fetch traces by ID. 

aws xray batch-get-traces --trace-ids 1-5f84c7a1-e7d1b9a2

الحصول على خريطة الخدمة. Get service graph. 

aws xray get-service-graph --start-time $(date -v-1H +%s) --end-time $(date +%s)

إدخال قاعدة أخذ عينات. Create sampling rule. 

aws xray create-sampling-rule --sampling-rule file://rule.json

تشغيل الـ daemon محلياً. Run local daemon. 

./xray -o -n us-east-1

تفعيل active tracing على Lambda. Enable Lambda active tracing. 

aws lambda update-function-configuration --function-name f --tracing-config Mode=Active

نصائح للامتحان Exam Tips

Lambda يحتاج tracing-config Mode=Active + IAM permissions (AWSXRayDaemonWriteAccess). Lambda needs tracing-config Mode=Active + IAM (AWSXRayDaemonWriteAccess).
EC2/ECS يتطلب تشغيل X-Ray daemon ليستقبل على UDP:2000 ويرسل إلى AWS. EC2/ECS require running the X-Ray daemon on UDP:2000 forwarding to AWS.
Annotations قابلة للفلترة في استعلامات X-Ray؛ Metadata للإطلاع فقط. Annotations are filterable in X-Ray queries; Metadata is view-only.
API Gateway يدعم X-Ray عبر تفعيل tracing على stage. API Gateway supports X-Ray via stage-level tracing toggle.
traces تُحفظ 30 يوم ولا يمكن تمديدها؛ للتحليل الطويل صدّرها أو استخدم CloudWatch. Traces retained 30 days and cannot be extended; export or combine with CloudWatch for longer analytics.
