ملخّص سريع Cheatsheet

Amazon EC2

سيرفرات افتراضية قابلة للتوسعة في السحابة مع أنواع instance متعدّدة وخيارات دفع مرنة. Scalable virtual servers with multiple instance types and flexible pricing.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Instance Types T/M (عام)، C (حوسبة)، R/X (ذاكرة)، I (IOPS)، G/P (GPU)، Mac (macOS). T/M (general), C (compute), R/X (memory), I (I/O), G/P (GPU), Mac (macOS).
Pricing Models On-Demand، Reserved (1y/3y)، Savings Plan، Spot (حتى 90% توفير)، Dedicated Host، Dedicated Instance. On-Demand, Reserved, Savings Plan, Spot (up to 90% off), Dedicated Host, Dedicated Instance.
AMI صورة قالب للـ instance تحتوي OS + تطبيقات مُسبّقة — خاصة/عامة/Marketplace. Image template with pre-installed OS + apps — private/public/marketplace.
Placement Groups Cluster (أداء عالي)، Spread (موزّع على hardware)، Partition (لتقسيم Hadoop/Kafka). Cluster (perf), Spread (across hardware), Partition (for Hadoop/Kafka).
User Data & Metadata User Data = سكريبت يعمل عند أول تشغيل. Metadata = http://169.254.169.254 لجلب معلومات الـ instance. User Data = script on first boot. Metadata = http://169.254.169.254 for instance info.
IMDSv2 الإصدار الآمن — يتطلّب session token ويمنع SSRF attacks. Secure version — requires session token, prevents SSRF.
ENI & Elastic IP ENI = بطاقة شبكة افتراضية، Elastic IP = IPv4 عام ثابت. ENI = virtual NIC; Elastic IP = static public IPv4.
Security Groups & NACLs SG على مستوى الـ instance (stateful)، NACL على subnet (stateless). SG at instance-level (stateful); NACL at subnet-level (stateless).

أوامر CLI الأساسية Essential CLI Commands

تشغيل instance جديد. Launch a new instance. 

aws ec2 run-instances --image-id ami-xxx --count 1 --instance-type t3.micro --key-name my-key --security-group-ids sg-xxx

عرض instances قيد التشغيل. List running instances. 

aws ec2 describe-instances --filters Name=instance-state-name,Values=running

إيقاف instance. Stop instance. 

aws ec2 stop-instances --instance-ids i-xxx

إنشاء AMI من instance. Create AMI from instance. 

aws ec2 create-image --instance-id i-xxx --name acme-web-v1

تطبيق Instance Profile (IAM Role). Attach instance profile. 

aws ec2 associate-iam-instance-profile --iam-instance-profile Name=AcmeAppRole --instance-id i-xxx

متى تستخدم Amazon EC2؟ When to use Amazon EC2

أعباء غير ثابتة/مفاجئة (dev/test). Bursty unpredictable workloads (dev/test).

On-Demand

أعباء مستقرّة لأكثر من سنة. Steady workloads > 1 year.

Reserved / Savings Plan

مهام قابلة للمقاطعة (Batch، CI). Interruptible jobs (Batch, CI).

Spot

HPC أو ML منخفض زمن الاستجابة. Low-latency HPC or ML.

Cluster Placement Group + enhanced networking

امتثال يتطلّب hardware مخصّص. Compliance requiring dedicated hardware.

نصائح للامتحان Exam Tips

Stop يحفظ البيانات على EBS، Terminate يحذفها (ما لم تُضبط DeleteOnTermination=false). Stop preserves EBS; Terminate deletes (unless DeleteOnTermination=false).
IMDSv2 إلزامي لمنع SSRF — اضبط HttpTokens=required. Enforce IMDSv2 to prevent SSRF — set HttpTokens=required.
Spot + On-Demand Base = مزيج فعّال للتوفير. Spot + On-Demand Base = cost-effective blend.
Cluster PG للأداء، Spread للاستقلالية، Partition لبيانات كبيرة. Cluster for perf, Spread for independence, Partition for big data.
لا تُخزّن مفاتيح AWS على الـ instance — استخدم IAM Role. Never store AWS keys on instance — use IAM Role.
