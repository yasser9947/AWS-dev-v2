AWS CodeCommit

مستودع Git خاص ومُدار بالكامل على AWS مع تشفير افتراضي وتكامل IAM وCloudWatch Events وSNS. Fully-managed private Git repository on AWS with default encryption, IAM integration, and CloudWatch Events / SNS hooks.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Private Git Repo مستودع Git عادي يدعم HTTPS/SSH والكلمات Git credential helper. Standard Git repo via HTTPS/SSH with Git credential helper support.
IAM-based access لا يوجد مستخدمين منفصلين؛ تُمنح صلاحيات عبر IAM policies. No separate users; permissions granted via IAM policies.
Authentication methods Git credentials (HTTPS) أو SSH keys أو git-remote-codecommit عبر AWS CLI. Git credentials (HTTPS), SSH keys, or git-remote-codecommit via AWS CLI.
Encryption تشفير in-transit (HTTPS/SSH) وat-rest عبر AWS KMS تلقائياً. In-transit (HTTPS/SSH) and at-rest encryption via AWS KMS by default.
Triggers SNS/Lambda عند أحداث push/merge لتشغيل CI/CD. SNS/Lambda on push/merge events to trigger CI/CD.
Notifications تكامل مع AWS Chatbot و SNS لإشعارات الفرق. AWS Chatbot and SNS integration for team notifications.
Approval Rule Templates قواعد مراجعة pull requests تفرض عدد الموافقين. Approval rule templates enforcing pull-request reviewer counts.
Cross-account access مشاركة عبر IAM role assume من حساب آخر. Sharing via IAM role assumption from another account.

أوامر CLI الأساسية Essential CLI Commands

إنشاء مستودع. Create repository. 

aws codecommit create-repository --repository-name my-repo

استنساخ عبر HTTPS مع credential helper. Clone via HTTPS with credential helper. 

git clone https://git-codecommit.us-east-1.amazonaws.com/v1/repos/my-repo

إنشاء pull request. Create pull request. 

aws codecommit create-pull-request --title 'PR' --targets 'repositoryName=my-repo,sourceReference=feature,destinationReference=main'

إضافة trigger SNS. Add SNS trigger. 

aws codecommit put-repository-triggers --repository-name my-repo --triggers file://triggers.json

إدراج الفروع. List branches. 

aws codecommit list-branches --repository-name my-repo

نصائح للامتحان Exam Tips

CodeCommit لا يملك IAM users خاصة به — الصلاحيات من IAM الحالي للحساب. CodeCommit has no own IAM users — permissions come from account's IAM.
للوصول HTTPS فعّل Git credentials في ملف تعريف IAM user أو استخدم git-remote-codecommit. For HTTPS, enable Git credentials on the IAM user or use git-remote-codecommit.
عمليات push/merge يمكنها استدعاء Lambda/SNS مباشرة كـ triggers. push/merge events can trigger Lambda/SNS directly as repository triggers.
Approval Rule Template يمكن تطبيقه على عدة repos في آن واحد لتوحيد سياسة المراجعة. Approval Rule Templates apply across multiple repos to standardize review policy.
CodeCommit Deprecation: AWS أعلنت إيقاف التسجيل للعملاء الجدد — الامتحان ما زال يغطي الخدمة. CodeCommit is in closed onboarding for new customers — exam still covers the service.
