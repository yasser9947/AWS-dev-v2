ملخّص سريع Cheatsheet

Amazon S3

تخزين كائنات متدرّج بدرجة متانة 11 تسعات، فئات تخزين متعدّدة، ونسخ متماثل وأحداث حسب الطلب. Durable (11 9s) object storage with multiple storage classes, replication, and event-driven integrations.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Buckets & Objects السطل (Bucket) حاوية عالمية الاسم، والكائن (Object) هو البيانات مع مفتاح وبيانات وصفية. Bucket is a globally unique container; object = data + key + metadata.
Storage Classes Standard، Intelligent-Tiering، Standard-IA، One Zone-IA، Glacier Instant/Flexible، Deep Archive. Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Instant/Flexible, Deep Archive.
Versioning & MFA Delete حفظ نسخ متعدّدة للكائن لحماية البيانات من الحذف/الكتابة فوقها، ويمكن اشتراط MFA للحذف الدائم. Keep multiple versions to protect against overwrite/delete; MFA Delete adds extra protection.
Server-Side Encryption SSE-S3 (AES-256)، SSE-KMS (مفاتيح KMS)، SSE-C (عميل يرسل المفتاح)، DSSE-KMS للتشفير المزدوج. SSE-S3 (AES-256), SSE-KMS, SSE-C, DSSE-KMS for dual-layer encryption.
Presigned URLs روابط موقّعة مؤقتًا تسمح بتحميل/رفع كائن دون الحاجة لصلاحيات AWS مباشرة. Time-limited signed URLs that allow get/put object without AWS credentials.
Lifecycle Policies قواعد لنقل الكائنات بين الفئات أو حذفها تلقائيًا بعد مدّة محدّدة. Rules that transition objects between classes or expire them automatically.
Cross/Same-Region Replication CRR/SRR لنسخ الكائنات إلى سطل آخر؛ يتطلّب تفعيل الإصدار على الطرفين. CRR/SRR replicate objects to another bucket; requires versioning on both buckets.
Event Notifications إطلاق أحداث عند الإنشاء/الحذف إلى SNS، SQS، Lambda، أو EventBridge. Fire events on create/delete to SNS, SQS, Lambda, or EventBridge.
Object Lock & Glacier Vault Lock وضع WORM لمنع الحذف/التعديل (Governance/Compliance) لأغراض الامتثال. WORM mode to prevent delete/modify (Governance/Compliance) for compliance.
Transfer Acceleration & Multipart تسريع الرفع عبر نقاط حافّة CloudFront، والرفع متعدّد الأجزاء للملفات الكبيرة. Upload via CloudFront edge (TA); multipart upload for large objects.

أوامر CLI الأساسية Essential CLI Commands

إنشاء سطل في منطقة محدّدة. Create a bucket in a specific region. 

aws s3api create-bucket --bucket my-app-data --region us-east-1

رفع ملف مع فئة تخزين Intelligent-Tiering. Upload a file with Intelligent-Tiering storage class. 

aws s3 cp report.pdf s3://my-app-data/ --storage-class INTELLIGENT_TIERING

مزامنة مجلّد محلّي مع سطل. Sync a local folder with a bucket. 

aws s3 sync ./build s3://my-app-data/build --delete

تفعيل الإصدارات على السطل. Enable versioning on the bucket. 

aws s3api put-bucket-versioning --bucket my-app-data --versioning-configuration Status=Enabled

إنشاء رابط موقّع يصلح لمدّة ساعة. Generate a presigned URL valid for 1 hour. 

aws s3 presign s3://my-app-data/report.pdf --expires-in 3600

ضبط سياسة دورة حياة من ملف JSON. Apply lifecycle policy from a JSON file. 

aws s3api put-bucket-lifecycle-configuration --bucket my-app-data --lifecycle-configuration file://lifecycle.json

متى تستخدم Amazon S3؟ When to use Amazon S3

أصول ثابتة لموقع ويب أو تطبيق جوال. Static assets for a web or mobile app.

S3 Standard + CloudFront

أرشفة سجلات طويلة الأجل بأقل تكلفة. Long-term log archives at lowest cost.

S3 Glacier Deep Archive

ملفات نادرة الوصول لكن تحتاج استرجاعًا فوريًا. Infrequent access but instant retrieval.

S3 Standard-IA / Glacier Instant Retrieval

بحيرة بيانات لتحليلات Athena أو EMR. Data lake for Athena / EMR analytics.

S3 + Parquet + partitioning

بيانات بأنماط وصول غير متوقعة. Data with unpredictable access patterns.

S3 Intelligent-Tiering

نصائح للامتحان Exam Tips

افصل بين العمليات: Multipart إلزامي لأكثر من 5 GB ومُوصى به لأكبر من 100 MB. Multipart upload is required for >5 GB and recommended for >100 MB objects.
Cross-Region Replication يتطلّب تفعيل الإصدار على السطل المصدر والهدف معًا. CRR requires versioning enabled on both source and destination buckets.
لتجاوز حدّ 3500 PUT/s وزّع الكائنات على بادئات متعدّدة. To exceed 3,500 PUT/s, distribute objects across multiple prefixes.
Presigned URLs تحمل صلاحيات الموقّع؛ إن انتهت جلسته تنتهي الروابط أيضًا. Presigned URLs inherit signer permissions; they expire with the signer session.
S3 Object Lock يتطلّب تفعيل الإصدار ولا يمكن تعطيله بعد إنشاء السطل في وضع Compliance. Object Lock needs versioning; Compliance mode cannot be disabled after enabling.
