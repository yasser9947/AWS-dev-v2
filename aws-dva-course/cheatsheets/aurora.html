ملخّص سريع Cheatsheet

Amazon Aurora

محرّك علائقي متوافق مع MySQL و PostgreSQL بأداء وتوفّر عاليَين وتخزين موزّع قابل للتوسّع التلقائي. MySQL-/PostgreSQL-compatible engine with high performance, availability, and auto-scaling distributed storage.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Cluster Architecture Writer واحد + حتى 15 Reader مع تخزين مشترك موزّع عبر 3 AZs. One Writer + up to 15 Readers sharing distributed storage across 3 AZs.
Storage Auto-Scaling ينمو من 10 GB إلى 128 TB تلقائيًا بدون downtime. Grows from 10 GB to 128 TB automatically with no downtime.
Six-Way Replication ست نسخ من البيانات (نسختان في كل AZ من 3) مع تحمّل فشل AZ كامل. Six copies (2 in each of 3 AZs) tolerates full AZ failure.
Endpoints Writer endpoint، Reader endpoint (موازنة تلقائية)، Custom endpoints لمجموعات معيّنة. Writer endpoint, Reader endpoint (auto load-balanced), Custom endpoints for groupings.
Aurora Serverless v2 يتوسّع بسلاسة بـ ACU من 0.5 إلى آلاف بدون فترات توقّف. Seamless scaling in ACUs from 0.5 to thousands with no downtime.
Global Database منطقة أساسية + 5 مناطق ثانوية بـ RPO < 1s و RTO < 1m. Primary + up to 5 secondary regions with RPO <1s and RTO <1m.
Backtrack رجوع بالقاعدة (MySQL-compat) لوقت سابق خلال ثوان دون استعادة. Rewind (MySQL-compat) to an earlier point in seconds without restore.
Parallel Query & Fast Clone تنفيذ استعلامات تحليلية على طبقة التخزين + نسخ فوري بدون تكلفة تخزين. Push analytical queries to storage layer; instant zero-cost clones.

أوامر CLI الأساسية Essential CLI Commands

إنشاء عنقود Aurora MySQL. Create an Aurora MySQL cluster. 

aws rds create-db-cluster --db-cluster-identifier prod-cluster --engine aurora-mysql --master-username admin --master-user-password ****

إضافة Writer instance للعنقود. Add a Writer instance to the cluster. 

aws rds create-db-instance --db-instance-identifier prod-writer --db-cluster-identifier prod-cluster --engine aurora-mysql --db-instance-class db.r6g.large

إضافة Reader instance. Add a Reader instance. 

aws rds create-db-instance --db-instance-identifier prod-reader-1 --db-cluster-identifier prod-cluster --engine aurora-mysql --db-instance-class db.r6g.large

تمكين Aurora Serverless v2. Enable Aurora Serverless v2. 

aws rds modify-db-cluster --db-cluster-identifier prod-cluster --serverless-v2-scaling-configuration MinCapacity=0.5,MaxCapacity=16

إنشاء Fast Clone من عنقود إنتاجي. Create a fast clone of a production cluster. 

aws rds restore-db-cluster-to-point-in-time --source-db-cluster-identifier prod-cluster --db-cluster-identifier prod-clone --restore-type copy-on-write --use-latest-restorable-time

متى تستخدم Amazon Aurora؟ When to use Amazon Aurora

تطبيق MySQL/PostgreSQL يحتاج أداء وتوفّر أعلى من RDS. MySQL/PostgreSQL app needing higher performance and availability than RDS.

Aurora

أحمال غير منتظمة (Dev/Test أو تطبيقات SaaS متعدّدة). Spiky workloads (dev/test, multi-tenant SaaS).

Aurora Serverless v2

تطبيق عالمي بزمن كتابة منخفض في عدّة قارّات. Global app with low-latency reads across regions.

Aurora Global Database

اختبار ترقية أو نسخة بيانات كبيرة دون تكلفة تخزين. Test an upgrade on a clone without extra storage cost.

Aurora Fast Clone

نصائح للامتحان Exam Tips

Aurora يخزّن 6 نسخ عبر 3 AZs ويتحمّل فقد نسختين للكتابة و 3 للقراءة. Aurora keeps 6 copies across 3 AZs; tolerates 2 lost copies for writes, 3 for reads.
Aurora Auto Scaling يضيف Reader instances حسب CPU/Connections. Aurora Auto Scaling adds Readers based on CPU or connection thresholds.
Global Database تصلح لـ DR بين المناطق بـ RPO < 1s. Global Database fits cross-region DR with sub-second RPO.
Serverless v2 يُوصى به للأحمال المتقطّعة (MySQL و PostgreSQL). Serverless v2 is recommended for intermittent workloads (MySQL & PostgreSQL).
Backtrack مختلف عن Restore؛ يرجع بالعنقود نفسه دون إنشاء جديد. Backtrack differs from restore — it rewinds the cluster in place.
