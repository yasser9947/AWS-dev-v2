ملخّص سريع Cheatsheet

Amazon API Gateway

بوّابة مُدارة لإنشاء واجهات REST و HTTP و WebSocket مع تحكّم بالأمان والحدّ من المعدّل والذاكرة المؤقتة. Managed gateway to build REST, HTTP, and WebSocket APIs with security, throttling, and caching.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
API Types REST API (كامل المزايا)، HTTP API (أخفّ وأسرع وأرخص)، WebSocket API للاتصالات ثنائية الاتجاه. REST API (full-featured), HTTP API (lighter, cheaper), WebSocket API for bi-directional.
Integrations Lambda، HTTP backend، AWS Service، Mock، VPC Link عبر NLB/ALB. Lambda, HTTP backend, AWS Service, Mock, VPC Link via NLB/ALB.
Stages & Deployments كل Stage (dev/prod) له مسار مستقل مع إعدادات ذاكرة مؤقتة وتسجيل. Each stage (dev/prod) has its own URL, cache, and logging settings.
Authorization IAM، Cognito User Pools، Lambda Authorizer (Token/Request)، JWT في HTTP API. IAM, Cognito User Pools, Lambda Authorizer (token/request), JWT on HTTP API.
Throttling & Usage Plans حدّ افتراضي 10,000 طلب/ثانية و 5,000 burst؛ API Keys + Usage Plans لكل عميل. Default 10,000 req/s and 5,000 burst; API Keys + Usage Plans per client.
Caching ذاكرة مؤقتة على مستوى المرحلة بحجم 0.5–237 GB وTTL قابل للضبط حتى ساعة. Stage-level cache 0.5–237 GB with TTL up to 1 hour.
Endpoint Types Edge-Optimized (CloudFront)، Regional، Private (VPC عبر VPC Endpoint). Edge-Optimized (CloudFront), Regional, Private (VPC via VPC Endpoint).
Request / Response Mapping تحويلات VTL لتحويل JSON/XML وتعديل رؤوس HTTP قبل/بعد الوصول. VTL templates to transform JSON/XML and headers pre/post integration.

أوامر CLI الأساسية Essential CLI Commands

إنشاء REST API. Create a REST API. 

aws apigateway create-rest-api --name "OrdersAPI" --endpoint-configuration types=REGIONAL

نشر مرحلة (stage). Deploy a stage. 

aws apigateway create-deployment --rest-api-id abcd1234 --stage-name prod

إنشاء HTTP API مرتبط بـ Lambda. Create an HTTP API with Lambda integration. 

aws apigatewayv2 create-api --name OrdersHTTP --protocol-type HTTP --target arn:aws:lambda:us-east-1:111:function:orders

ضبط حدّ Throttling على Stage. Set throttling on a stage. 

aws apigateway update-stage --rest-api-id abcd1234 --stage-name prod --patch-operations op=replace,path=/*/*/throttling/rateLimit,value=1000

إنشاء Usage Plan مع API Key. Create a usage plan with an API key. 

aws apigateway create-usage-plan --name basic --throttle rateLimit=100,burstLimit=200 --quota limit=10000,period=MONTH

متى تستخدم Amazon API Gateway؟ When to use Amazon API Gateway

واجهة REST كاملة مع Authorizers و Usage Plans و Caching. Full-featured REST API with authorizers, usage plans, caching.

REST API

واجهة خفيفة وسريعة لـ Lambda بتكلفة أقل. Lightweight low-cost API for Lambda.

HTTP API

دردشة مباشرة أو لوحات تحديثات فورية. Live chat or real-time dashboards.

WebSocket API

API داخلي ضمن VPC فقط. Internal API within a VPC only.

Private REST API

نصائح للامتحان Exam Tips

حدّ 29 ثانية لكل نداء؛ المهام الطويلة تحتاج Step Functions أو SQS ثم Lambda. 29-second timeout per invoke; long jobs need Step Functions or SQS + Lambda.
HTTP API أرخص وأسرع ولكن REST API لديه MORE features (Resource Policies, WAF, Cache). HTTP API is cheaper/faster; REST API has more features (Resource Policies, WAF, Cache).
Edge-Optimized يستخدم CloudFront تلقائيًا ولا يدار من حسابك. Edge-Optimized uses AWS-managed CloudFront (not visible in your account).
Usage Plans يعملان مع REST API فقط؛ لمعدّلات HTTP API استخدم Route throttling. Usage Plans work with REST API only; use Route throttling for HTTP API.
Lambda Authorizer نوعان: TOKEN (يعتمد على header) و REQUEST (كامل الطلب). Lambda Authorizers come in TOKEN (header-based) and REQUEST (full request) flavors.
