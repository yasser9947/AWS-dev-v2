ملخّص سريع Cheatsheet

Amazon DynamoDB

قاعدة بيانات NoSQL مُدارة بالكامل، زمن استجابة أقل من 10 مللي ثانية، وتوسّع أفقي بلا حدود. Fully managed NoSQL database with single-digit millisecond latency and unbounded horizontal scale.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Tables & Items جدول يحوي عناصر (Items) ولكلّ عنصر سمات (Attributes)؛ المخطّط مرن باستثناء مفتاح الأساسي. Tables hold items with attributes; schema is flexible except for the primary key.
Primary Key Partition Key فقط، أو Composite Key (Partition + Sort) لتجميع العناصر. Partition Key only, or Composite (Partition + Sort) to group items.
GSI vs LSI GSI: مفتاح مختلف تمامًا ويُدار منفصلًا. LSI: نفس الـ Partition بمفتاح فرز بديل ويُنشأ وقت إنشاء الجدول فقط. GSI: different keys, independent capacity. LSI: same partition, alt sort key; only at table creation.
Capacity Modes On-Demand (تلقائي) أو Provisioned مع Auto Scaling؛ Provisioned أرخص للأعباء المستقرّة. On-Demand (automatic) or Provisioned with Auto Scaling; Provisioned cheaper for steady loads.
Read Consistency القراءة الافتراضية Eventually Consistent (نصف RCU)، ويمكن طلب Strongly Consistent (RCU كامل). Default reads are eventually consistent (½ RCU); you can request strongly consistent (full RCU).
Transactions حتى 100 عنصر أو 4 MB لكل معاملة عبر TransactWriteItems/TransactGetItems (ضعف استهلاك WCU/RCU). Up to 100 items or 4 MB per TransactWriteItems/TransactGetItems (2× WCU/RCU).
Streams & DAX Streams لتغذية Lambda ورصد التغيّرات، وDAX cache داخل VPC لخفض زمن القراءة إلى ميكروثانية. Streams trigger Lambda for change data capture; DAX VPC cache for microsecond reads.
TTL حذف تلقائي للعناصر منتهية الصلاحية بدون استهلاك WCU. Auto-delete expired items without consuming WCUs.
Global Tables نسخ متعدّد المناطق بالكتابة من أي منطقة مع دقّة Eventually Consistent. Multi-region multi-active replication, eventual consistency.

أوامر CLI الأساسية Essential CLI Commands

إنشاء جدول On-Demand. Create an on-demand table. 

aws dynamodb create-table --table-name Orders --attribute-definitions AttributeName=OrderId,AttributeType=S --key-schema AttributeName=OrderId,KeyType=HASH --billing-mode PAY_PER_REQUEST

كتابة عنصر. Put an item. 

aws dynamodb put-item --table-name Orders --item '{"OrderId":{"S":"O1"},"Total":{"N":"99"}}'

تنفيذ Query على Composite Key. Query a composite-key table. 

aws dynamodb query --table-name Orders --key-condition-expression "CustomerId = :c" --expression-attribute-values '{":c":{"S":"CUST-1"}}'

تفعيل Streams نوع NEW_AND_OLD_IMAGES. Enable streams with NEW_AND_OLD_IMAGES. 

aws dynamodb update-table --table-name Orders --stream-specification StreamEnabled=true,StreamViewType=NEW_AND_OLD_IMAGES

تفعيل TTL. Enable TTL. 

aws dynamodb update-time-to-live --table-name Orders --time-to-live-specification Enabled=true,AttributeName=expireAt

إضافة جدول عالمي في منطقة ثانية. Add a Global Table region. 

aws dynamodb update-table --table-name Orders --replica-updates 'Create={RegionName=eu-west-1}'

نصائح للامتحان Exam Tips

كل عنصر ≤ 400 KB؛ خزّن الكبيرة في S3 واحفظ المفتاح في DynamoDB. Item ≤ 400 KB; store large objects in S3 and keep the pointer in DynamoDB.
LSI يُنشأ وقت إنشاء الجدول فقط؛ GSI يمكن إضافتها لاحقًا. LSIs can only be created at table creation; GSIs can be added later.
Strongly Consistent Read يستهلك RCU كاملة؛ الافتراضي Eventually نصفها. Strongly consistent reads cost full RCU; default eventual consistency costs half.
Transactions تستهلك ضعف WCU/RCU للقراءة/الكتابة. Transactions consume 2× the WCU/RCU of regular reads/writes.
استخدم Streams + Lambda لتنفيذ CDC (مثل تحديث OpenSearch أو إرسال Email). Use Streams + Lambda for CDC (e.g., update OpenSearch, send email).
