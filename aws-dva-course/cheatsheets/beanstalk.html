Elastic Beanstalk

منصّة PaaS لنشر تطبيقات الويب بسرعة دون إدارة الـ infrastructure. PaaS platform for rapid web app deployment without managing infrastructure.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Application & Environment Application = حاوية منطقية، Environment = مثيل مُشغّل (Web أو Worker Tier). Application = logical container; Environment = running instance (Web or Worker Tier).
Web Tier vs Worker Tier Web يستقبل HTTP عبر ALB، Worker يقرأ من SQS لمهام خلفية طويلة. Web serves HTTP via ALB; Worker polls SQS for long background jobs.
Supported Platforms Java، Python، Node.js، Ruby، PHP، Go، .NET، Docker (single/multi-container). Java, Python, Node.js, Ruby, PHP, Go, .NET, Docker (single/multi-container).
Deployment Policies All at once، Rolling، Rolling with batch، Immutable، Traffic Splitting. All at once, Rolling, Rolling with additional batch, Immutable, Traffic Splitting.
.ebextensions ملفات YAML/JSON في مجلّد .ebextensions لتخصيص البنية التحتية والخدمات. YAML/JSON files in .ebextensions folder for infra/service customization.
RDS Decoupling لا تُنشئ RDS داخل البيئة في الإنتاج — يُحذف مع البيئة. اربطها كمصدر خارجي. Don't create RDS inside environment in prod — it dies with the env. Link as external.
Blue/Green via Swap URLs نشر نسخة جديدة في بيئة منفصلة ثم تبديل الـ CNAMEs بين البيئتين لصفر downtime. Deploy new version in separate env and swap CNAMEs between them for zero downtime.
EB CLI eb init، eb create، eb deploy، eb status، eb logs — أدوات لكل دورة الحياة. eb init, eb create, eb deploy, eb status, eb logs — full lifecycle tools.

أوامر CLI الأساسية Essential CLI Commands

تهيئة مشروع جديد. Init a new project. 

eb init -p python-3.11 acme-api

إنشاء بيئة جديدة. Create environment. 

eb create prod-env --instance-type t3.small --elb-type application

نشر إصدار جديد. Deploy new version. 

eb deploy prod-env

تبديل بيئات Blue/Green. Swap environment URLs. 

eb swap prod-env --destination-name staging-env

عرض السجلات. Stream logs. 

eb logs --all

نصائح للامتحان Exam Tips

Immutable = أأمن طريقة نشر — ينشئ instances جديدة ثم يحوّل الحركة. Immutable = safest deploy — new instances then shift traffic.
لا تضع RDS داخل بيئة الإنتاج — افصلها. Don't put RDS inside prod env — decouple it.
.ebextensions > platform hooks > resources لتخصيص البيئة. .ebextensions > platform hooks > resources to customize env.
Swap URLs = Blue/Green deploy بسيط وسريع. Swap URLs = simple fast blue/green.
Traffic Splitting = Canary لـ Beanstalk. Traffic Splitting = Beanstalk's Canary.
