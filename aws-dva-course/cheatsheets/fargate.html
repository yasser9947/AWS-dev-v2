ملخّص سريع Cheatsheet

AWS Fargate

تشغيل حاويات بدون إدارة خوادم — يدعم ECS و EKS. Run containers without managing servers — supports ECS and EKS.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Serverless Containers AWS يدير الخوادم، أنت تحدّد فقط vCPU والذاكرة للمهمّة. AWS manages servers; you only specify vCPU + memory per task.
Task-Level Networking كل task يحصل على ENI و IP خاص — يعمل داخل subnet من VPC. Each task gets its own ENI + IP — runs in a VPC subnet.
Pricing Model تدفع للـ vCPU والذاكرة فقط لمدّة تشغيل الـ task — بالثانية. Pay only for vCPU + memory per task duration — per-second billing.
Fargate Spot خصم حتى 70% لأعباء قابلة للمقاطعة — AWS تنبّه قبل إنهاء الـ task بدقيقتين. Up to 70% off for interruptible workloads — 2-min termination notice.
Fargate on EKS Fargate Profile يُحدّد الـ namespaces/labels التي تعمل على Fargate. Fargate Profile determines which namespaces/labels run on Fargate.
Storage 20 GB ephemeral افتراضي، حتى 200 GB عبر ephemeralStorage parameter. 20 GB ephemeral default, up to 200 GB via ephemeralStorage parameter.
No Privileged Mode لا يدعم privileged containers — يقيد بعض حالات الاستخدام (Docker-in-Docker). No privileged containers — limits some use cases (Docker-in-Docker).

أوامر CLI الأساسية Essential CLI Commands

تشغيل task على Fargate. Run task on Fargate. 

aws ecs run-task --cluster acme --task-definition web:1 --launch-type FARGATE --network-configuration 'awsvpcConfiguration={subnets=[subnet-xxx],securityGroups=[sg-xxx],assignPublicIp=ENABLED}'

إنشاء service على Fargate. Create Fargate service. 

aws ecs create-service --cluster acme --service-name api --task-definition api:3 --launch-type FARGATE --desired-count 2 --network-configuration '...'

إنشاء Fargate Profile لـ EKS. Create EKS Fargate Profile. 

aws eks create-fargate-profile --fargate-profile-name api --cluster-name acme --pod-execution-role-arn arn:... --selectors namespace=api

تفعيل capacity provider Spot. Enable Fargate Spot. 

aws ecs put-cluster-capacity-providers --cluster acme --capacity-providers FARGATE FARGATE_SPOT

متى تستخدم AWS Fargate؟ When to use AWS Fargate

microservices بدون إدارة خوادم. Microservices with zero server management.

Fargate on ECS

Kubernetes بدون إدارة Worker Nodes. K8s without managing Worker Nodes.

Fargate on EKS

مهام Batch مؤقّتة متقطّعة. Bursty Batch jobs.

Fargate Spot + AWS Batch

مهام تتطلّب GPU/kernel tweaks. GPU or kernel-level workloads.

ECS/EKS on EC2 (not Fargate)

نصائح للامتحان Exam Tips

Fargate = لا إدارة EC2 — AWS تتعامل مع patching والتوسعة. Fargate = no EC2 to manage — AWS handles patching + scaling.
Fargate لا يدعم privileged — استخدم EC2 إذا احتجت Docker-in-Docker. Fargate doesn't support privileged — use EC2 for Docker-in-Docker.
Spot أرخص لكنّه قابل للمقاطعة — ليس للـ API الحسّاسة. Spot is cheaper but preemptable — not for critical APIs.
يدفع على وقت الـ task فقط — ممتاز للأحمال المتغيّرة. Pays only for task runtime — ideal for variable loads.
