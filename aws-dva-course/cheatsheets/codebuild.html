AWS CodeBuild

خدمة بناء مُدارة بلا خوادم تُنفّذ buildspec.yml في بيئات مُدارة أو مخصّصة مع دفع حسب الدقيقة. Fully managed serverless build service running buildspec.yml in managed or custom environments with per-minute billing.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
buildspec.yml ملف في جذر المصدر يصف مراحل install/pre_build/build/post_build والمخرجات artifacts. File at source root defining install/pre_build/build/post_build phases and artifacts.
Phases install (أدوات), pre_build (auth/setup), build (التنفيذ), post_build (الختم/النشر). install (tools), pre_build (auth/setup), build (run), post_build (finalize/deploy).
Environment صورة Docker مُدارة من AWS أو مخصّصة من ECR؛ تحدّد compute (SMALL/MEDIUM/LARGE/2XLARGE). Managed AWS Docker image or custom ECR image; compute size SMALL/MEDIUM/LARGE/2XLARGE.
Artifacts مخرجات تُرفع إلى S3 (أو secondary artifacts). Outputs uploaded to S3 (with optional secondary artifacts).
Cache S3 cache أو local cache (DOCKER_LAYER/SOURCE/CUSTOM) لتسريع البناء. S3 cache or local cache (DOCKER_LAYER/SOURCE/CUSTOM) to speed builds.
Environment variables Plaintext أو parameter-store أو secrets-manager لحقن القيم. Plaintext, parameter-store, or secrets-manager references injected as vars.
VPC support تشغيل builds داخل VPC للوصول إلى RDS أو موارد خاصة. Run builds inside VPC to reach RDS or private resources.
Reports دعم JUnit/Cucumber لعرض نتائج الاختبارات في Console. JUnit/Cucumber test report support visible in console.

أوامر CLI الأساسية Essential CLI Commands

إنشاء مشروع بناء. Create build project. 

aws codebuild create-project --name my-build --source type=CODECOMMIT,location=... --environment ... --service-role arn:... --artifacts type=S3,location=my-bucket

بدء بناء. Start a build. 

aws codebuild start-build --project-name my-build

متابعة بناء. Check a build. 

aws codebuild batch-get-builds --ids my-build:abcd-1234

قائمة المشاريع. List projects. 

aws codebuild list-projects

إيقاف بناء. Stop build. 

aws codebuild stop-build --id my-build:abcd-1234

نصائح للامتحان Exam Tips

buildspec.yml يستخدم phases: install/pre_build/build/post_build؛ artifacts ترفع إلى S3. buildspec.yml uses phases: install/pre_build/build/post_build; artifacts upload to S3.
env.parameter-store يرجع قيمة من SSM، وenv.secrets-manager يرجع من Secrets Manager. env.parameter-store pulls from SSM; env.secrets-manager pulls from Secrets Manager.
CodeBuild افتراضياً خارج VPC؛ فعّل VPC config للوصول إلى RDS الخاصة. CodeBuild runs outside VPC by default; enable VPC config for private RDS access.
يستطيع CodeBuild بناء صور Docker ودفعها إلى ECR عبر privileged mode. CodeBuild can build Docker images and push to ECR with privileged mode enabled.
CodeBuild يتكامل مع CodePipeline كـ build action وينتج/يستهلك artifacts تلقائياً. CodeBuild integrates with CodePipeline as a build action, auto-producing/consuming artifacts.
