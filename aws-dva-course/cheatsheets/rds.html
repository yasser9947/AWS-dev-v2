Amazon RDS

قواعد بيانات علائقية مُدارة (MySQL, PostgreSQL, MariaDB, Oracle, SQL Server) مع تصحيحات ونسخ احتياطي آلي. Managed relational databases (MySQL, PostgreSQL, MariaDB, Oracle, SQL Server) with automated patching and backups.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
DB Instances خادم قاعدة بيانات على EC2 مُدار بـ RDS بفئات db.t/db.m/db.r/db.x. A managed DB server on EC2 with db.t/db.m/db.r/db.x classes.
Multi-AZ Deployment نسخة احتياطية متزامنة في AZ مختلفة لتحسين HA؛ تحوّل تلقائي عند الفشل. Synchronous standby in another AZ for HA; automatic failover.
Read Replicas حتى 15 نسخة قراءة غير متزامنة داخل/عبر المناطق لتوسيع أحمال القراءة. Up to 15 async read replicas within/cross-region to scale reads.
Automated Backups & Snapshots نسخ احتياطي آلي يومي مع نافذة احتفاظ حتى 35 يومًا، ولقطات يدوية. Daily automated backups up to 35 days retention; plus manual snapshots.
Encryption & IAM Auth تشفير KMS في الراحة (يجب تفعيله عند الإنشاء)، وSSL/TLS في النقل، ومصادقة IAM لـ MySQL/PostgreSQL. KMS at rest (must enable at creation), SSL/TLS in transit, IAM auth for MySQL/PostgreSQL.
Parameter & Option Groups تخصيص إعدادات المحرّك وتفعيل خصائص (مثل TDE أو memcached). Customize engine parameters and enable features (TDE, memcached).
RDS Proxy يجمع الاتصالات ويحسّن التعامل مع Lambda ويقلّل تأثير الفشل. Connection pooling, better Lambda handling, and reduced failover impact.
Storage Auto-Scaling يتوسّع التخزين تلقائيًا حتى حدّ تحدّده أنت. Storage auto-scales up to a max you define.

أوامر CLI الأساسية Essential CLI Commands

إنشاء قاعدة MySQL Multi-AZ مشفّرة. Create an encrypted Multi-AZ MySQL instance. 

aws rds create-db-instance --db-instance-identifier prod-db --engine mysql --db-instance-class db.m6g.large --allocated-storage 100 --multi-az --storage-encrypted --master-username admin --master-user-password ****

إنشاء نسخة قراءة. Create a read replica. 

aws rds create-db-instance-read-replica --db-instance-identifier prod-db-ro --source-db-instance-identifier prod-db

أخذ لقطة يدوية. Take a manual snapshot. 

aws rds create-db-snapshot --db-instance-identifier prod-db --db-snapshot-identifier prod-db-2026-04-23

الاستعادة إلى وقت محدّد. Point-in-time restore. 

aws rds restore-db-instance-to-point-in-time --source-db-instance-identifier prod-db --target-db-instance-identifier prod-db-restored --restore-time 2026-04-22T10:00:00Z

تمكين مصادقة IAM. Enable IAM authentication. 

aws rds modify-db-instance --db-instance-identifier prod-db --enable-iam-database-authentication --apply-immediately

متى تستخدم Amazon RDS؟ When to use Amazon RDS

تطبيق يستخدم SQL تقليدي مع جداول علائقية. Classic SQL app with relational tables.

RDS MySQL / PostgreSQL

أحمال تحتاج HA تلقائيًا مع RPO قريب من الصفر. Workloads needing automatic HA, near-zero RPO.

RDS Multi-AZ

تطبيق سحابي بلا خادم يتصل بقاعدة بيانات. Serverless app connecting to a database.

RDS Proxy + Lambda

تقليل أثر استعلامات التقارير على الإنتاج. Offload reporting queries from prod.

نصائح للامتحان Exam Tips

Multi-AZ للتوفّر العالي (ليس للأداء)، Read Replicas لتوسعة القراءة. Multi-AZ is for HA (not performance); Read Replicas scale reads.
لا يمكن تشفير قاعدة بعد إنشائها؛ استعد من لقطة مشفّرة بدلاً من ذلك. You cannot encrypt an existing unencrypted DB; restore from an encrypted snapshot.
RDS Proxy يقلّل فشل الاتصالات ويسرّع تحوّل Multi-AZ ويناسب Lambda. RDS Proxy reduces connection storms, speeds Multi-AZ failover, and fits Lambda.
PITR يعتمد على transaction logs المستمرّة خلال فترة الاحتفاظ. Point-in-time restore relies on continuous transaction logs within retention.
لتحويل نسخة قراءة إلى مستقلة: استخدم promote-read-replica. Use promote-read-replica to turn a read replica into a standalone primary.
