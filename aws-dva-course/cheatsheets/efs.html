Amazon EFS

نظام ملفّات NFS مُدار يتمدّد تلقائيًا ويدعم وصول متزامن من آلاف المثيلات عبر AZs. Managed NFS filesystem that auto-scales and supports concurrent access from thousands of instances across AZs.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
NFSv4 Protocol يُستخدم من Linux عبر NFSv4.1؛ لا يدعم Windows (لذلك استخدم FSx بدلاً منه). Uses NFSv4.1 from Linux; no Windows support (use FSx instead).
Performance Modes General Purpose (افتراضي) وMax I/O لعدد عمليات كبير مع زمن استجابة أعلى قليلاً. General Purpose (default) and Max I/O for very high op counts at slightly higher latency.
Throughput Modes Bursting (افتراضي)، Provisioned، Elastic التي تتمدّد حسب الطلب. Bursting (default), Provisioned, and Elastic that auto-scales with demand.
Storage Classes EFS Standard وEFS Infrequent Access (IA) وArchive بإدارة عبر Lifecycle. EFS Standard, Infrequent Access (IA), and Archive managed via Lifecycle.
Access Points نقاط دخول تُطبّق مستخدم POSIX ومجلّد جذر لكل تطبيق. Entry points enforcing a POSIX user and root directory per application.
Security تشفير عبر KMS في الراحة وTLS في النقل، ومجموعات أمان على mount targets. KMS encryption at rest, TLS in transit, security groups on mount targets.
Mount Targets نقطة ربط في كل AZ داخل الـ VPC ليصل إليها EC2 محلياً. One mount target per AZ in the VPC so EC2 can mount locally.
Replication نسخ المحتوى إلى منطقة أخرى لأغراض DR مع RPO ≤ دقيقة. Replicate to another region for DR with RPO ≤ 1 minute.

أوامر CLI الأساسية Essential CLI Commands

إنشاء نظام ملفّات EFS. Create an EFS filesystem. 

aws efs create-file-system --creation-token app-data --performance-mode generalPurpose --encrypted

إنشاء mount target في AZ معيّنة. Create a mount target in an AZ. 

aws efs create-mount-target --file-system-id fs-0abcd --subnet-id subnet-0abcd --security-groups sg-0abcd

تثبيت EFS على EC2 عبر amazon-efs-utils. Mount EFS on EC2 via amazon-efs-utils. 

sudo mount -t efs -o tls fs-0abcd:/ /mnt/efs

ضبط Lifecycle لنقل الملفّات إلى IA بعد 30 يومًا. Set Lifecycle to move files to IA after 30 days. 

aws efs put-lifecycle-configuration --file-system-id fs-0abcd --lifecycle-policies TransitionToIA=AFTER_30_DAYS

إنشاء Access Point لتطبيق محدّد. Create an Access Point for a specific app. 

aws efs create-access-point --file-system-id fs-0abcd --posix-user Uid=1000,Gid=1000 --root-directory Path=/app

خوادم ويب متعدّدة تحتاج مشاركة حالة جلسة أو محتوى. Many web servers sharing session or content.

نصائح للامتحان Exam Tips

EFS هو NFS للينكس فقط؛ لـ Windows استخدم FSx for Windows File Server. EFS is NFS Linux-only; for Windows use FSx for Windows File Server.
EFS إقليمي ومتاح عبر AZs، بعكس EBS المقيّد بـ AZ واحدة. EFS is Regional and multi-AZ, unlike EBS which is AZ-bound.
Access Points تُلزم POSIX UID/GID وجذر محدّد لكل تطبيق. Access Points enforce POSIX UID/GID and a chroot-like root per application.
Lifecycle Policies تنقل الملفّات إلى IA/Archive تلقائيًا لتقليل التكلفة. Lifecycle policies move files to IA/Archive automatically to cut cost.
