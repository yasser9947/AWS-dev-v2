ملخّص سريع Cheatsheet

Amazon SNS

خدمة نشر/اشتراك (Pub/Sub) لتوزيع الرسائل إلى عدّة مستهلكين عبر SQS و Lambda و HTTP و Email و SMS. Pub/Sub service that fans messages out to many subscribers via SQS, Lambda, HTTP, Email, and SMS.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Topics & Subscribers ينشر المُنتِج رسالة إلى Topic وتصل إلى كل المشتركين (fan-out). Producer publishes to a Topic; each subscriber receives a copy (fan-out).
Standard vs FIFO Standard يعمل at-least-once وبترتيب غير مضمون. FIFO ترتيب وexactly-once مع SQS FIFO. Standard: at-least-once, best-effort ordering. FIFO: ordered & exactly-once (with SQS FIFO).
Delivery Protocols SQS، Lambda، HTTP(S)، Email، SMS، Mobile Push، Kinesis Data Firehose. SQS, Lambda, HTTP(S), Email, SMS, Mobile Push, Kinesis Data Firehose.
Message Filtering فلاتر على خصائص الرسالة أو body لإيصالها فقط للمشتركين المعنيّين. Filters on message attributes or body to deliver only to relevant subscribers.
Retry & DLQ سياسة إعادة محاولة قابلة للتكوين + DLQ (SQS) لكل اشتراك. Configurable retry policy + subscription-level DLQ (SQS).
Encryption SSE عبر KMS للرسائل في الراحة، و HTTPS للنقل. KMS-based SSE at rest, HTTPS in transit.
Access Control Topic Policies (Resource-based) + IAM للمنشورين والمشتركين. Topic policies (resource-based) + IAM for publishers/subscribers.
Mobile Push APNs، FCM، ADM لإشعارات الجوّال. APNs, FCM, ADM for mobile push notifications.

أوامر CLI الأساسية Essential CLI Commands

إنشاء Topic. Create a topic. 

aws sns create-topic --name orders-topic

إنشاء Topic من نوع FIFO. Create a FIFO topic. 

aws sns create-topic --name orders-topic.fifo --attributes FifoTopic=true,ContentBasedDeduplication=true

اشتراك طابور SQS في Topic. Subscribe an SQS queue to a topic. 

aws sns subscribe --topic-arn arn:aws:sns:us-east-1:111:orders-topic --protocol sqs --notification-endpoint arn:aws:sqs:us-east-1:111:orders

نشر رسالة مع خصائص للفلترة. Publish a message with filter attributes. 

aws sns publish --topic-arn arn:aws:sns:us-east-1:111:orders-topic --message '{"id":42}' --message-attributes 'region={DataType=String,StringValue=EU}'

تمكين فلتر على الاشتراك. Set a subscription filter policy. 

aws sns set-subscription-attributes --subscription-arn arn:aws:sns:...:SubId --attribute-name FilterPolicy --attribute-value '{"region":["EU"]}'

إرسال SMS مباشر. Send a direct SMS. 

aws sns publish --phone-number +15550123 --message "OTP 4321"

نصائح للامتحان Exam Tips

نمط Fan-out الكلاسيكي: SNS → عدة SQS لضمان استقلالية المستهلكين. Classic fan-out pattern: SNS → multiple SQS queues for consumer independence.
Message Filtering يقلّل استهلاك المستهلكين غير المعنيّين. Message filtering reduces useless deliveries to uninterested subscribers.
SNS FIFO يتكامل فقط مع SQS FIFO كمشترك للحفاظ على الترتيب. SNS FIFO only integrates with SQS FIFO subscribers to preserve order.
DLQ في SNS مُعرَّف على مستوى الاشتراك وليس Topic. DLQ in SNS is defined per-subscription, not per-topic.
للرسائل > 256 KB استخدم مكتبة SNS Extended Client مع S3. For payloads > 256 KB use the SNS Extended Client Library with S3.
