ملخّص سريع Cheatsheet

Amazon ElastiCache

ذاكرة تخزين مؤقت مُدارة داخل الذاكرة بـ Redis/Valkey أو Memcached لسرعة استجابة بالمايكروثانية. Managed in-memory cache with Redis/Valkey or Memcached delivering microsecond latency.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Redis/Valkey vs Memcached Redis/Valkey: بنى بيانات غنية، دائمية، نسخ احتياطي، Replication. Memcached: بسيط بلا استمرارية بل multi-threaded. Redis/Valkey: rich data types, persistence, replication. Memcached: simple, multi-threaded, no persistence.
Cluster Mode (Redis) Cluster Mode Disabled: node master + replicas. Enabled: sharding عبر 1-500 shard. Cluster Mode Disabled: 1 master + replicas. Enabled: sharded across 1–500 shards.
Replication & Failover Redis يدعم Multi-AZ مع auto-failover، Memcached لا يدعم replication. Redis supports Multi-AZ with automatic failover; Memcached doesn’t support replication.
Data Tiering يخزّن البيانات النادرة على SSD مع الإبقاء على الساخنة في الذاكرة (r6gd). Stores less-frequently accessed data on SSD while keeping hot data in memory (r6gd).
Encryption & Auth TLS في النقل، KMS في الراحة، Redis AUTH + IAM Auth. TLS in transit, KMS at rest, Redis AUTH + IAM Auth.
Lazy Loading vs Write-Through Lazy: اقرأ من DB عند miss وخزّن. Write-Through: حدّث الكاش مع الكتابة. Lazy loading: populate on cache miss; Write-through: update cache with every write.
Eviction Policies allkeys-lru، volatile-lru، LFU، random، noeviction عند امتلاء الذاكرة. allkeys-lru, volatile-lru, LFU, random, noeviction when memory fills.
Global Datastore (Redis) نسخ عبر المناطق لقراءة منخفضة الكمون وDR. Cross-region replication for low-latency reads and DR.

أوامر CLI الأساسية Essential CLI Commands

إنشاء عنقود Redis مع Multi-AZ. Create a Redis cluster with Multi-AZ. 

aws elasticache create-replication-group --replication-group-id prod-cache --engine redis --cache-node-type cache.r6g.large --num-cache-clusters 2 --automatic-failover-enabled

إنشاء عنقود Memcached بـ 3 nodes. Create a Memcached cluster with 3 nodes. 

aws elasticache create-cache-cluster --cache-cluster-id sessions --engine memcached --cache-node-type cache.t3.medium --num-cache-nodes 3

تمكين TLS في النقل. Enable TLS in transit. 

aws elasticache create-replication-group --replication-group-id secure-cache --transit-encryption-enabled --auth-token MySecret --engine redis

إنشاء لقطة يدوية لـ Redis. Create a manual Redis snapshot. 

aws elasticache create-snapshot --replication-group-id prod-cache --snapshot-name manual-2026-04-23

توسيع عدد replicas. Increase replica count. 

aws elasticache increase-replica-count --replication-group-id prod-cache --new-replica-count 3 --apply-immediately

متى تستخدم Amazon ElastiCache؟ When to use Amazon ElastiCache

كاش قاعدة بيانات لتقليل زمن القراءة. Database cache to reduce read latency.

Redis/Valkey (Cluster Mode)

مخزن جلسات مركزي لتطبيق ويب خلف ELB. Centralized session store for web app behind ELB.

Redis / Memcached

قوائم متصدّرين وPub/Sub وعدّادات ذرّية. Leaderboards, Pub/Sub, atomic counters.

Redis data structures

تخزين مؤقت بسيط متعدّد الخيوط بأقل تكلفة. Simple multi-threaded cache at lowest cost.

نصائح للامتحان Exam Tips

اختر Redis عند الحاجة للـ Replication/Persistence؛ اختر Memcached للتخزين البسيط والتوسّع متعدّد الخيوط. Choose Redis when you need replication/persistence; Memcached for simple multi-threaded caching.
ElastiCache يعيش داخل VPC؛ افتح منفذ 6379 (Redis) أو 11211 (Memcached). ElastiCache lives in a VPC; open port 6379 (Redis) or 11211 (Memcached).
لخفض حمل DB استخدم Lazy Loading مع TTL. To reduce DB load, combine lazy loading with TTL expiration.
Auto-Failover يعمل فقط على Redis في وضع Multi-AZ. Auto-failover only works on Redis with Multi-AZ enabled.
