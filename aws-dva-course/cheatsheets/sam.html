ملخّص سريع Cheatsheet

AWS SAM

إطار عمل لتطبيقات Serverless: قالب مختصر يتوسّع إلى CloudFormation مع أوامر sam للبناء والاختبار المحلي والنشر. Serverless application framework: concise template expanded to CloudFormation with sam commands for build, local test, and deploy.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Transform: AWS::Serverless-2016-10-31 توجيه يُفعّل الـ macro الذي يحوّل الموارد المختصرة إلى CloudFormation. Directive activating the macro that expands shorthand into CloudFormation.
AWS::Serverless::Function مورد مختصر لـ Lambda مع Events وPolicies وLayers. Shorthand Lambda resource with Events, Policies, and Layers.
AWS::Serverless::Api مورد مختصر لـ API Gateway REST/HTTP مع stages وauth. Shorthand API Gateway REST/HTTP with stages and auth.
Events محفّزات: Api, HttpApi, S3, SQS, SNS, Schedule, DynamoDB, Kinesis. Triggers: Api, HttpApi, S3, SQS, SNS, Schedule, DynamoDB, Kinesis.
Policies (SAM policy templates) قوالب جاهزة مثل S3CrudPolicy و DynamoDBCrudPolicy لتبسيط IAM. Ready templates like S3CrudPolicy, DynamoDBCrudPolicy simplifying IAM.
sam build يبني كل function في .aws-sam/build مع تبعياتها. Builds each function into .aws-sam/build with its dependencies.
sam local اختبار محلي لـ Lambda وAPI عبر Docker. Local testing of Lambda and API via Docker.
sam deploy --guided ينشر المجموعة إلى CloudFormation بحوار تفاعلي. Deploys stack to CloudFormation with an interactive wizard.
AutoPublishAlias + DeploymentPreference نشر ملاحي لـ Lambda Canary/Linear مع CodeDeploy مدمج. Lambda traffic-shifting Canary/Linear via built-in CodeDeploy integration.

أوامر CLI الأساسية Essential CLI Commands

تهيئة مشروع جديد. Initialize a new project. 

sam init --runtime python3.12 --name my-app

بناء الدوال وتبعياتها. Build functions and dependencies. 

sam build --use-container

اختبار محلي لـ API. Run API locally. 

sam local start-api

استدعاء دالة محلياً بحدث. Invoke function locally with event. 

sam local invoke HelloFunction --event events/event.json

نشر بحوار تفاعلي. Deploy with guided wizard. 

sam deploy --guided

مشاهدة السجلات. Tail logs. 

sam logs -n HelloFunction --stack-name my-app --tail

نصائح للامتحان Exam Tips

SAM هو ماكرو CloudFormation — يتطلب CAPABILITY_AUTO_EXPAND عند الـ create/update. SAM is a CloudFormation macro — requires CAPABILITY_AUTO_EXPAND on create/update.
DeploymentPreference: Canary10Percent5Minutes / Linear10PercentEvery1Minute / AllAtOnce للـ Lambda. DeploymentPreference: Canary10Percent5Minutes / Linear10PercentEvery1Minute / AllAtOnce for Lambda.
sam build يحل التبعيات عبر Docker container يطابق runtime الإنتاج (استخدم --use-container). sam build resolves dependencies via Docker container matching runtime (use --use-container).
Policies في Function تستخدم قوالب جاهزة — تبسّط IAM كثيراً مقارنة بكتابة policies يدوياً. Function Policies use ready templates — much simpler than hand-written IAM.
sam deploy يعتمد samconfig.toml لحفظ خيارات النشر بين المرات. sam deploy uses samconfig.toml to persist deploy options across runs.
