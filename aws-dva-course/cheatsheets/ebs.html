ملخّص سريع Cheatsheet

Amazon EBS

تخزين كتلي دائم يرتبط بمثيلات EC2 داخل نفس نطاق التوفّر مع لقطات آمنة في S3. Persistent block storage attached to EC2 within an AZ, with snapshots backed by S3.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Volume Types gp3/gp2 (SSD عام)، io2/io1 (SSD عالي الأداء)، st1 (HDD متسلسل)، sc1 (HDD بارد). gp3/gp2 (general SSD), io2/io1 (provisioned IOPS), st1 (throughput HDD), sc1 (cold HDD).
AZ-Scoped حجم EBS يعيش داخل AZ واحدة ولا يمكن ربطه بمثيل في AZ أخرى مباشرة. An EBS volume lives in a single AZ; cannot attach to an instance in another AZ directly.
Snapshots لقطات تفاضلية تُخزّن في S3، يمكن نسخها عبر المناطق والحسابات. Incremental snapshots stored in S3; copyable across Regions and accounts.
Encryption تشفير الحجم والبيانات أثناء الراحة والنقل عبر KMS؛ اللقطات الناتجة مشفّرة أيضًا. Volume & data encryption at rest and in transit via KMS; resulting snapshots also encrypted.
Multi-Attach يدعم io1/io2 ربط نفس الحجم بمثيلات Nitro متعدّدة داخل نفس AZ. io1/io2 support attaching the same volume to multiple Nitro instances in one AZ.
Elastic Volumes تعديل الحجم والنوع والـ IOPS بدون إيقاف المثيل. Modify size, type, and IOPS without stopping the instance.
Data Lifecycle Manager أتمتة إنشاء اللقطات والاحتفاظ بها ومسحها وفق جدول محدّد. Automate snapshot creation, retention, and deletion on a schedule.
Fast Snapshot Restore تفعيل الاستعادة الفورية للقطة دون تأخير أوّل قراءة. Eliminate first-touch latency when restoring from a snapshot.

أوامر CLI الأساسية Essential CLI Commands

إنشاء حجم gp3 بحجم 100 GiB في AZ. Create a 100 GiB gp3 volume in an AZ. 

aws ec2 create-volume --volume-type gp3 --size 100 --availability-zone us-east-1a --encrypted

ربط الحجم بمثيل EC2. Attach the volume to an EC2 instance. 

aws ec2 attach-volume --volume-id vol-0abcd --instance-id i-0abcd --device /dev/sdf

إنشاء لقطة من حجم EBS. Create a snapshot from an EBS volume. 

aws ec2 create-snapshot --volume-id vol-0abcd --description "nightly"

نسخ لقطة إلى منطقة أخرى. Copy a snapshot to another region. 

aws ec2 copy-snapshot --source-region us-east-1 --source-snapshot-id snap-0abcd --destination-region eu-west-1

تعديل حجم gp2 وترقيته إلى gp3. Modify a gp2 volume and upgrade to gp3. 

aws ec2 modify-volume --volume-id vol-0abcd --volume-type gp3 --iops 6000 --throughput 250

متى تستخدم Amazon EBS؟ When to use Amazon EBS

قاعدة بيانات عالية الأداء على EC2. High-performance database on EC2.

io2 Block Express

تطبيق عام بتكلفة وأداء متوازنين. General-purpose workloads with balanced cost.

gp3

أحمال تسلسلية كبيرة مثل Big Data. Large sequential workloads like Big Data.

st1 (Throughput-optimized HDD)

أرشفة بوصول نادر وسعر منخفض. Infrequent-access archival at low cost.

sc1 (Cold HDD)

نصائح للامتحان Exam Tips

لا يمكن ربط حجم EBS بمثيل في AZ مختلفة؛ الحلّ إنشاء لقطة ثمّ استعادتها في AZ الهدف. You cannot attach EBS across AZs; snapshot and restore it in the target AZ.
gp3 ترقية مباشرة لـ gp2 مع IOPS و Throughput قابلَين للتكوين المستقل. gp3 replaces gp2 and lets you provision IOPS and throughput independently.
اللقطات تفاضلية وتُخزّن في S3 المُدار من AWS (لا يظهر في حسابك). Snapshots are incremental and stored in AWS-managed S3 (not visible in your account).
تشفير حجم غير مشفّر يتطلّب: لقطة → نسخة مشفّرة → حجم جديد منها. To encrypt an unencrypted volume: snapshot → encrypted copy → new volume from copy.
Multi-Attach يتطلّب نظام ملفّات متوافق مع المشاركة مثل GFS2 أو Lustre. Multi-Attach requires a clustered filesystem such as GFS2 or Lustre.
