AWS CDK

تعريف البنية التحتية بكود حقيقي (TS/Python/Java/Go/.NET) يُترجم إلى CloudFormation بواسطة cdk synth. Define infrastructure in real code (TS/Python/Java/Go/.NET) that synthesizes to CloudFormation via cdk synth.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Construct اللبنة الأساسية؛ L1 (Cfn) يطابق CFN، L2 مبسّطة، L3 (Patterns) مجمّعة. Building block; L1 (Cfn) mirrors CFN, L2 simplified, L3 (Patterns) composed.
Stack حاوية موارد تُترجم إلى CloudFormation stack واحد. Resource container mapped to a single CloudFormation stack.
App الجذر يحتوي على stacks متعددة ومنطق النشر. Root containing multiple stacks and deployment logic.
cdk synth يولّد قالب CloudFormation من الكود. Generates the CloudFormation template from code.
cdk deploy / destroy ينشر أو يحذف stack عبر CloudFormation. Deploys or destroys stack via CloudFormation.
cdk bootstrap ينشئ CDKToolkit stack (S3 + ECR + IAM) في الحساب/المنطقة قبل أول نشر. Creates CDKToolkit stack (S3 + ECR + IAM) in account/region before first deploy.
Context قيم في cdk.json / cdk.context.json لتخزين بيانات البيئة. Values in cdk.json / cdk.context.json storing environment data.
Assets ملفات/صور Docker تُرفع تلقائياً لـ S3/ECR أثناء النشر. Files/Docker images auto-uploaded to S3/ECR during deployment.
Aspects & Tags تطبيق سياسات/وسوم تلقائياً على كل موارد Construct. Apply policies/tags automatically across all child constructs.

أوامر CLI الأساسية Essential CLI Commands

تهيئة مشروع TypeScript. Init TypeScript project. 

cdk init app --language typescript

تهيئة الحساب/المنطقة للنشر. Bootstrap account/region. 

cdk bootstrap aws://123456789012/us-east-1

توليد قالب CloudFormation. Synthesize CloudFormation template. 

cdk synth

نشر جميع stacks. Deploy all stacks. 

cdk deploy --all --require-approval never

الفرق بين الكود والمنشور. Diff between code and deployed. 

cdk diff MyStack

حذف stack. Destroy stack. 

cdk destroy MyStack

نصائح للامتحان Exam Tips

CDK يولّد CloudFormation template — أي حد في CFN (500 مورد/1MB) ينطبق أيضاً. CDK synthesizes CloudFormation — CFN limits (500 resources / 1MB) apply.
cdk bootstrap إلزامي قبل أول deploy في كل account+region لإنشاء CDKToolkit stack. cdk bootstrap is mandatory before first deploy per account+region (creates CDKToolkit stack).
L1 = Cfn* classes (مطابقة CFN)؛ L2 = friendly defaults؛ L3 = patterns (مثل ApplicationLoadBalancedFargateService). L1 = Cfn* classes (CFN mirror); L2 = friendly defaults; L3 = patterns (e.g. ApplicationLoadBalancedFargateService).
cdk diff يستخدم CloudFormation API لمعاينة التغيير دون نشر فعلي. cdk diff uses CloudFormation API to preview changes without deploying.
Assets تُنسخ تلقائياً إلى bucket الـ bootstrap عبر cdk deploy. Assets are auto-uploaded to the bootstrap bucket during cdk deploy.
