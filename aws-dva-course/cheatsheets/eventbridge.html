ملخّص سريع Cheatsheet

Amazon EventBridge

ناقل أحداث مُدار بلا خوادم يربط التطبيقات عبر قواعد ومخطّطات وجداول زمنية للتنسيق بين الخدمات. Serverless event bus that connects applications through rules, schemas, and schedules for service orchestration.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Event Bus ناقل يستقبل الأحداث؛ يوجد default و custom و partner (SaaS). Receives events; types: default, custom, and partner (SaaS) event buses.
Rule تطابق نمط الحدث أو جدول زمني وتوجّه إلى target واحد أو أكثر (حتى 5). Matches event pattern or schedule and routes to up to 5 targets.
Event Pattern مرشّح JSON يطابق source/detail-type/detail لتصفية الأحداث. JSON filter matching source/detail-type/detail fields for event selection.
Targets أكثر من 20 وجهة: Lambda, SQS, SNS, Step Functions, Kinesis, ECS task, API Destination. 20+ destinations: Lambda, SQS, SNS, Step Functions, Kinesis, ECS task, API Destination.
Schema Registry يكتشف ويخزن مخطّطات الأحداث وينشئ code bindings لـ Java/Python/TS. Discovers and stores event schemas; generates code bindings for Java/Python/TS.
Scheduler EventBridge Scheduler: جدولة cron/rate لمرة واحدة أو متكررة بدقة عالية ومقياس كبير. EventBridge Scheduler: one-time/recurring cron/rate scheduling at high scale.
Archive & Replay يخزّن الأحداث لفترة محددة ويُعيد تشغيلها لاختبار السيناريوهات. Archives events for a retention period and replays them for testing.
API Destinations استدعاء HTTPS endpoints خارجية عبر connections مع OAuth/API Key. Invoke external HTTPS endpoints using connections with OAuth/API Key auth.
Pipes EventBridge Pipes: point-to-point من مصدر (SQS/Kinesis/DynamoDB Streams) إلى هدف مع filter/enrich. EventBridge Pipes: point-to-point source (SQS/Kinesis/DynamoDB Streams) to target with filter/enrich.

أوامر CLI الأساسية Essential CLI Commands

إنشاء قاعدة مجدولة بمعدل. Create schedule-based rule. 

aws events put-rule --name nightly-rule --schedule-expression 'rate(1 day)'

إنشاء قاعدة بنمط حدث. Create rule with event pattern. 

aws events put-rule --name s3-upload --event-pattern '{"source":["aws.s3"],"detail-type":["Object Created"]}'

إضافة هدف Lambda للقاعدة. Add Lambda target to rule. 

aws events put-targets --rule s3-upload --targets 'Id=1,Arn=arn:aws:lambda:us-east-1:123:function:proc'

إرسال حدث مخصص. Put custom event. 

aws events put-events --entries 'Source=my.app,DetailType=OrderPlaced,Detail={"id":"1"}'

إنشاء جدولة عبر Scheduler. Create schedule via Scheduler. 

aws scheduler create-schedule --name daily --schedule-expression 'cron(0 9 * * ? *)' --target '{...}' --flexible-time-window '{"Mode":"OFF"}'

نصائح للامتحان Exam Tips

EventBridge Scheduler هو الخليفة الحديث لـ CloudWatch Events scheduled rules؛ استخدمه للجداول الجديدة. EventBridge Scheduler is the modern successor to CloudWatch Events scheduled rules for new schedules.
عند وجود SaaS event source اختر Partner event bus وليس ناقل مخصص. For SaaS sources pick Partner event bus — not a custom bus.
نمط الحدث يطابق مصفوفة واحدة على الأقل؛ حقول غير موجودة لا تُطابَق. Event pattern must match at least one array; missing fields don't match.
لإعادة معالجة الأحداث بعد حادث، فعّل Archive ثم استخدم Replay. To reprocess events after an incident, enable Archive then use Replay.
EventBridge Pipes يدعم filter + enrich (Lambda/Step Functions) قبل التسليم. EventBridge Pipes supports filter + enrich (Lambda/Step Functions) before delivery.
