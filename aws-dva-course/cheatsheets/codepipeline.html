AWS CodePipeline

محرّك CI/CD مُنظَّم يربط Source→Build→Test→Deploy كمراحل (Stages) تحتوي Actions تتعامل مع Artifacts. Managed CI/CD engine linking Source→Build→Test→Deploy as Stages with Actions passing Artifacts.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Pipeline تدفّق مراحل يتنفّذ عند كل تغيير مصدر. Stage flow executing on every source change.
Stage حاوية Actions متسلسلة أو متوازية (Source/Build/Test/Deploy/Approval). Container of sequential or parallel Actions (Source/Build/Test/Deploy/Approval).
Action خطوة تنفيذ (CodeBuild, CodeDeploy, CloudFormation, Lambda, ECS, Manual approval, custom). Execution step (CodeBuild, CodeDeploy, CloudFormation, Lambda, ECS, Manual approval, custom).
Artifacts تُخزَّن في S3 artifact bucket وتُمرَّر بين actions (input/output). Stored in S3 artifact bucket and passed between actions (input/output).
Source providers CodeCommit, GitHub (v1/v2 via Connections), Bitbucket, S3, ECR. CodeCommit, GitHub (v1/v2 via Connections), Bitbucket, S3, ECR.
Manual Approval توقّف المسار بانتظار IAM principal يوافق (مع SNS notify). Pipeline pauses for an IAM principal to approve (with optional SNS notify).
Cross-region actions Actions في مناطق أخرى عبر replication bucket و artifact stores متعددة. Actions in other regions via replication bucket and multiple artifact stores.
Variables قيم ناتجة من action تمر كـ #{SourceVariables.CommitId} لاستعمالها لاحقاً. Action outputs referenced as #{SourceVariables.CommitId} in later stages.

أوامر CLI الأساسية Essential CLI Commands

إنشاء pipeline من ملف تعريف. Create pipeline from definition. 

aws codepipeline create-pipeline --pipeline file://pipeline.json

بدء تنفيذ يدوي. Start pipeline execution manually. 

aws codepipeline start-pipeline-execution --name my-pipeline

استرجاع حالة pipeline. Get pipeline state. 

aws codepipeline get-pipeline-state --name my-pipeline

الموافقة اليدوية. Approve manual action. 

aws codepipeline put-approval-result --pipeline-name my-pipeline --stage-name Deploy --action-name Approve --result status=Approved,summary=ok --token TOKEN

إعادة محاولة الإجراءات الفاشلة في المرحلة. Retry failed actions in stage. 

aws codepipeline retry-stage-execution --pipeline-name my-pipeline --stage-name Deploy --pipeline-execution-id abc --retry-mode FAILED_ACTIONS

نصائح للامتحان Exam Tips

كل pipeline يحتاج artifact bucket في S3؛ cross-region يتطلب buckets متعددة. Every pipeline needs an S3 artifact bucket; cross-region needs multiple buckets.
Manual Approval يرسل SNS notification وينتظر put-approval-result مع token. Manual Approval sends SNS notification and waits for put-approval-result with a token.
Source من CodeCommit يستخدم CloudWatch Events (default) بدلاً من polling للسرعة. CodeCommit source uses CloudWatch Events (default) instead of polling for faster trigger.
GitHub v2 = CodeStar Connection (OAuth)؛ GitHub v1 = personal access token (deprecated). GitHub v2 = CodeStar Connection (OAuth); GitHub v1 = personal access token (legacy).
Actions من نوع Invoke (Lambda) مفيدة لخطوات مخصّصة (tests/notifications). Invoke (Lambda) action enables custom steps like tests/notifications.
