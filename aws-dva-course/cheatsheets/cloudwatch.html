Amazon CloudWatch

منصّة المراقبة: Metrics وLogs وAlarms وEvents وDashboards وSynthetics لرؤية شاملة لصحة وأداء الأنظمة. Observability platform: Metrics, Logs, Alarms, Events, Dashboards, Synthetics for end-to-end system health and performance.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
Metrics سلاسل زمنية موزّعة على namespaces/dimensions؛ standard كل دقيقة، detailed/custom بدقة أعلى. Time series grouped by namespace/dimensions; standard per minute, detailed/custom higher resolution.
High-resolution metric خصوصية 1 ثانية عبر PutMetricData StorageResolution=1. 1-second granularity via PutMetricData StorageResolution=1.
Logs CloudWatch Logs: Log Groups → Log Streams؛ retention قابل للضبط 1 يوم – Never Expire. CloudWatch Logs: Log Groups → Log Streams; retention 1 day – Never Expire.
Logs Insights استعلام SQL-like على log groups (5 خلف المجموعات كحد). SQL-like query over log groups (up to 50 groups per query).
Metric Filter يستخرج أرقام من Logs ويحوّلها إلى CloudWatch metric. Extracts values from Logs into a CloudWatch metric.
Alarms حالات OK/INSUFFICIENT_DATA/ALARM على metric؛ تشغّل SNS, Auto Scaling, EC2 action. OK/INSUFFICIENT_DATA/ALARM states on a metric; trigger SNS, Auto Scaling, or EC2 actions.
Composite Alarm يجمع عدة alarms بتعابير AND/OR لتقليل noise. Combines multiple alarms via AND/OR rule expressions to reduce noise.
Synthetics Canaries سكربتات Lambda (Puppeteer/Selenium) تفحص endpoints دورياً. Lambda scripts (Puppeteer/Selenium) periodically probing endpoints.
CloudWatch Agent يجمع system metrics ولوجات من EC2/On-Prem عبر ملف JSON config. Collects system metrics and logs from EC2/On-Prem via JSON config.

أوامر CLI الأساسية Essential CLI Commands

نشر metric مخصص. Publish a custom metric. 

aws cloudwatch put-metric-data --namespace MyApp --metric-name Orders --value 1 --unit Count

إنشاء alarm على CPU. Create CPU alarm. 

aws cloudwatch put-metric-alarm --alarm-name high-cpu --metric-name CPUUtilization --namespace AWS/EC2 --threshold 80 --comparison-operator GreaterThanThreshold --evaluation-periods 2 --period 60 --statistic Average --alarm-actions arn:aws:sns:...

استعلام Logs Insights. Run Logs Insights query. 

aws logs start-query --log-group-name /aws/lambda/f --start-time 1700000000 --end-time 1700003600 --query-string 'fields @timestamp,@message | filter @message like /ERROR/'

تصدير لوجات إلى S3. Export logs to S3. 

aws logs create-export-task --log-group-name /aws/lambda/f --from 1700000000000 --to 1700003600000 --destination my-bucket

ضبط احتفاظ log group. Set log group retention. 

aws logs put-retention-policy --log-group-name /aws/lambda/f --retention-in-days 30

نصائح للامتحان Exam Tips

1-minute metrics تُحفظ 15 يوم، 5-minute 63 يوم، 1-hour 455 يوم (15 شهر). 1-min metrics retained 15 days, 5-min 63 days, 1-hour 455 days (15 months).
High-resolution (1s) alarms ممكنة فقط مع custom metrics StorageResolution=1 ويدعمها period=10s أو 30s. High-res (1s) alarms only with custom metrics StorageResolution=1 and period 10s or 30s.
EC2 Standard Monitoring = كل 5 دقائق؛ Detailed Monitoring = كل دقيقة (مدفوع). EC2 Standard Monitoring = every 5 min; Detailed Monitoring = every 1 min (paid).
Metric Filter يحوّل لوجات إلى metric — لا يغيّر محتوى اللوج ولا يعيد معالجة قديمة. Metric Filter turns logs into a metric — doesn't modify logs or process history.
Alarm يدخل INSUFFICIENT_DATA عندما لا توجد datapoints — يمكن اعتبارها OK أو ALARM. Alarm enters INSUFFICIENT_DATA on missing data — treat as OK or ALARM via TreatMissingData.
