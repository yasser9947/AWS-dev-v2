ملخّص سريع Cheatsheet

AWS Step Functions

خدمة تنسيق سير العمل بلا خوادم تُبنى سير عمل (state machines) باستخدام ASL لربط Lambda وخدمات AWS بمنطق قوي. Serverless workflow orchestration using ASL to compose Lambda and AWS services into reliable state machines.

المفاهيم الأساسية Key Concepts

المفهوم Concept الوصف Description
State Machine تعريف سير العمل بلغة Amazon States Language (JSON). Workflow definition authored in Amazon States Language (JSON).
Standard Workflow exactly-once، مدّة حتى سنة، مثالي للأعمال الطويلة والمدقّقة. Exactly-once, up to 1 year duration, ideal for long-running audited jobs.
Express Workflow at-least-once، مدّة حتى 5 دقائق، ذو معدل عالٍ وتكلفة أقل لكل تنفيذ. At-least-once, up to 5 min duration, high TPS and lower per-execution cost.
Task State يستدعي Lambda/خدمة AWS عبر SDK أو Optimized integration. Invokes Lambda/AWS service via SDK or optimized integration.
Choice / Parallel / Map Choice للتفرع، Parallel للفروع المتزامنة، Map للتكرار على مصفوفة. Choice for branching, Parallel for concurrent branches, Map for array iteration.
Wait / Pass / Succeed / Fail حالات للتأخير، تمرير البيانات، إنهاء ناجح، أو فشل صريح. States for delay, data passing, success termination, or explicit failure.
Retry & Catch إعادة محاولة مع backoff وتقاط الأخطاء لمسار بديل. Retry with backoff and Catch errors to alternate paths.
Callback pattern (.waitForTaskToken) انتظار حتى يستدعي عامل خارجي SendTaskSuccess/Failure. Pause until an external worker calls SendTaskSuccess/Failure.
Activities مهام تُنفَّذ بواسطة عمال خارج AWS عبر long polling. Tasks executed by external workers via long polling.

أوامر CLI الأساسية Essential CLI Commands

إنشاء state machine من ملف تعريف. Create a state machine from a definition file. 

aws stepfunctions create-state-machine --name order-flow --definition file://asl.json --role-arn arn:aws:iam::123:role/StepFnRole --type STANDARD

بدء تنفيذ مع إدخال JSON. Start execution with JSON input. 

aws stepfunctions start-execution --state-machine-arn arn:aws:states:...:order-flow --input '{"orderId":"123"}'

متابعة حالة تنفيذ. Describe execution state. 

aws stepfunctions describe-execution --execution-arn arn:aws:states:...:exec-1

إرسال نجاح مهمة callback. Send task success for callback. 

aws stepfunctions send-task-success --task-token $TOKEN --output '{"status":"ok"}'

بدء تنفيذ Express متزامن. Start synchronous Express execution. 

aws stepfunctions start-sync-execution --state-machine-arn arn:aws:states:...:express-sm --input '{}'

نصائح للامتحان Exam Tips

Standard = exactly-once حتى سنة؛ Express = at-least-once حتى 5 دقائق. السؤال غالباً يختبر الفرق. Standard = exactly-once up to 1 year; Express = at-least-once up to 5 min. Commonly tested distinction.
لاستدعاء إنسان/API خارجي بانتظار طويل استخدم .waitForTaskToken مع SendTaskSuccess. For long external/human callbacks use .waitForTaskToken with SendTaskSuccess.
Map Distributed يوزّع حتى 10,000 تنفيذ فرعي ممتاز لمعالجة S3 الكبيرة. Distributed Map scales to 10,000 child executions for large S3 processing.
Express لا يحفظ تاريخاً مفصلاً — اعتمد على CloudWatch Logs/X-Ray. Express keeps no detailed history — rely on CloudWatch Logs/X-Ray.
Retry يستخدم exponential backoff؛ Catch ينقل إلى حالة ErrorHandler. Retry uses exponential backoff; Catch routes to an ErrorHandler state.
